HIL-SERL：人在旁边扶一把，机器人在真机上自己练成

外号 · 「陪练教练」机器人自己试错，快出事时人扶一把，裁判只说成没成

在真机上直接做强化学习（RL）一向很难：试一次要几十秒，奖励不好写，乱动还会撞坏东西。HIL-SERL 把四样东西拼在一起：几十条人类示教、一个“看图判成败”的奖励分类器、人随时接管纠正、一个很省样本的离线策略 RL 算法（基于 RLPD 的 SAC）。结果是 1 到 2.5 小时真机训练，多数任务成功率接近 100%。

03四个零件，一个一个看

3.1 裁判：奖励分类器

先用遥操作录一些画面。有的帧任务成功，标 1；有的没成功，标 0。拿这些图训一个小的图像分类器。训练 RL 时，每一步把相机画面喂给它，它说成功，这一步奖励就是 1，episode 结束。

Q2奖励来自一个二分类器，输入是相机图像，输出“成功的概率”。超过阈值就算成功，给奖励 success_reward，并结束这一回合。其他时候奖励是 0。所以这是稀疏奖励：只有成功那一下有分。 人也可以用手柄直接按“成功”，这时奖励由人给。 分类器打分:611判成功:619人按成功:517predict_reward:279论文 §3.3 Reward

3.2 陪练：人工干预

训练时，人手里拿着手柄或键盘。机器人在自己跑。人看它要出错（比如要撞桌子、卡住不动），就按住接管键，用手柄推着它走。松开键，控制权还给策略。

代码里只做了一件事：如果这一帧“人在干预”，就把策略的动作替换成人的动作，然后把 is_intervention=True 记进这条数据。

Q3人在策略要犯大错时插手，短时间纠正后马上放手。插手那几帧的数据（动作是人的）会进两个缓冲区：在线缓冲区，和装示教的离线缓冲区。其他帧只进在线缓冲区。 这样人的纠正和示教一样，会在每个 batch 里被多次采到。 替换动作:494读干预标记:357进在线:982干预也进离线:985论文 §3.4

怎么干预才好

LeRobot 文档给的建议：刚开始让策略自己探索几回合；不要长时间接管，只在跑偏时纠正一下；策略开始会做之后，只做“帮它抓一下”这种很短的干预。健康的训练里，干预率（人接管的步数 ÷ 总步数）会逐渐降到 0。 mdx:902干预率:402

示意图：人插手越来越少，成功率越来越高。真实曲线见论文附录 E 和 LeRobot 文档的干预率图。

3.3 示教 + 混合采样：为什么学得快

训练开始前，先录几十条成功的示教，放进离线缓冲区。机器人自己跑出的经验放进在线缓冲区。每次训练取一个 batch，一半从在线取，一半从离线取。这是 RLPD 的“对称采样”。

Q4快的原因有三个：
  1. 离线策略：每条经验存进缓冲区，可以被拿出来训很多次，不是用一次就扔。
  2. 示教一直在 batch 里：一半样本来自示教和人纠正，critic 一开始就见到“成功的路”，不用靠乱试撞上。
  3. 人纠正：把策略从坏状态拉回来，少浪费尝试。论文的消融里，去掉人干预的任务成功率掉得很多。
LeRobot 里 online_ratio 默认 0.5；utd_ratio（每收一批数据做几次梯度更新）默认 1，可以调大。 n_online:62online_ratio=0.5:41utd_ratio:80UTD 循环:201RLPD 论文

3.4 学习的核心：SAC 怎么更新（逐步推）

先说大白话：有两个网络。critic 是“打分员”，给（画面，动作）打分，分数代表“这么做以后大概能拿多少奖励”。actor 是“出手的人”，学着选打分员给高分的动作，同时别太死板。

critic 的更新（目标：让 Q(s,a) 等于“这一步奖励 + 以后的价值”）

  1. 在下一状态抽一个动作。用当前 actor 在 s' 抽 a' ~ π(·|s')，同时得到 log π(a'|s')。为什么：要估“下一步之后还能拿多少”，需要知道下一步大概会怎么做。
  2. 两个目标网络打分，取小的那个。q̄ = min(Q̄₁(s',a'), Q̄₂(s',a'))。为什么：单个网络爱高估，取小更保守。min:303
  3. 减掉熵项。q̄ ← q̄ − α·log π(a'|s')。为什么：−log π 越大表示越随机，这一项等于把“保持随机”也算作一种收益。熵项:305
  4. 拼出目标值。y = r + γ·(1 − done)·q̄。为什么：回合结束了就没有“以后”，所以乘 (1−done)。td_target:307
  5. 让两个 critic 都去拟合 y。损失是 (Q₁(s,a) − y)² + (Q₂(s,a) − y)² 的平均。critic loss:271

算一个数

设 r=0, done=0, γ=0.99, α=0.1，两个目标网络给 0.8 和 0.7，log π(a'|s') = −1。
第 2 步：取小 → 0.7。第 3 步：0.7 − 0.1×(−1) = 0.8。第 4 步：y = 0 + 0.99×1×0.8 = 0.792。
如果 Q₁(s,a) 现在是 0.6，误差是 0.6 − 0.792 = −0.192，梯度会把它往上推。

actor 的更新（目标：选打分高的动作，但别太死板）

  1. 在当前状态抽动作。a ~ π(·|s)，带着梯度（重参数化），得到 log π(a|s)。
  2. 两个 critic 打分取小。q = min(Q₁(s,a), Q₂(s,a))。
  3. 损失 = α·log π(a|s) − q，取平均。为什么：要让 q 变大（减号），也要让 log π 变小、即更随机（α 控制力度）。actor loss:407

温度 α 的更新（自动调“随机性”的力度）

  1. 损失 = −α·(log π(a|s) + H̄)。temperature loss:419
  2. 怎么读：如果策略太确定，log π 偏大，log π + H̄ > 0，梯度让 α 变大，更鼓励随机。反过来太随机，α 变小。默认 H̄ = −动作维度/2。target_entropy:125

目标网络慢慢跟：θ̄ ← 0.005·θ + 0.995·θ̄。每次只挪一小步，目标值 y 不会乱跳，训练更稳。soft update:4220.005:58

3.5 夹爪：单独一个离散 critic

手臂移动是连续的（往哪挪几毫米）。夹爪本质上只有三种选择：闭、不动、开。用连续高斯去学“开 / 关”很别扭，常常抖来抖去。

Q5论文把夹爪当成离散动作，单独用一个 DQN 式的 critic 学：给“闭 / 不动 / 开”各打一个分，选最高的。目标值是 r + 夹爪惩罚 + γ·Q̄_g(s', 下一步最好的夹爪动作)。 夹爪惩罚很小（默认 −0.02）：夹爪已经开着还下令“开”，或已经关着还下令“关”，就扣一点，防止它没事乱动夹爪。 discrete critic:335读惩罚:354penalty=-0.02:368num_discrete_actions:141论文 §3.3 Gripper

08读完做几道题

先自己想，再点开看答案。

  1. 奖励分类器把一个失败画面误判成成功，会发生什么？

    看答案
    这一步拿到奖励 1，回合也结束。critic 会学到“走到这种画面就好”，策略可能学会“骗过裁判”而不是真的完成任务。所以分类器要多喂难分的失败帧，阈值也要调。见 Q2。hil_processor.py:619

  2. 人干预的那几帧，为什么还要多放一份进离线缓冲区？

    看答案
    离线缓冲区固定占每个 batch 的一半，而它的数据量小，所以里面每条被采到的次数多。人纠正的帧放进去，就会像示教一样被反复学到。见 Q3。learner.py:985

  3. critic 目标值里，为什么要乘 (1 − done)？

    看答案
    回合结束（成功或超时）后没有“下一步”，以后的价值是 0，目标值只剩 r。见 3.4 第 4 步。sac_algorithm.py:307

  4. 按 3.4 的例子，如果两个目标网络给 0.9 和 0.5，其他不变，y 是多少？

    看答案
    取小 → 0.5；减熵项 0.5 + 0.1 = 0.6；y = 0.99 × 0.6 = 0.594。

  5. 策略越来越确定，温度 α 会怎么变？

    看答案
    log π 变大，log π + H̄ 变正，温度损失的梯度让 α 变大，更鼓励随机。见 3.4 温度。sac_algorithm.py:419

  6. HIL-SERL 和 HG-DAgger 都有人接管。最大的不同在哪？

    看答案
    HG-DAgger 把人的动作当标签去模仿，上限是人。HIL-SERL 把人的动作当成一条好经验，最终按奖励学，失败的尝试也有用，可以比人更快。见 第 06 节。

  7. actor 连不上 learner 的那几秒，机器人会停下来吗？

    看答案
