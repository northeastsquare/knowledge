强化学习要怎么接进来？

这一页不按论文年份罗列，而是按问题走：先看三个决定路线的旋钮，再看地铁图里的四条线，然后按时间讲七个站，最后停在 2026 年今天还没解决的问题上。

5 条路线 2024 → 2026 仿真 vs 真机 冻结 vs 整模型

00先拧三个旋钮

所有 VLA+RL 方法，本质上都在回答三个问题。拖动下面的滑块，看看哪条路线最像你的情况。

旋钮 A · 改多少？

只改小头/残差整个模型都改

旋钮 B · 奖励从哪来？

仿真里大批量真机 + 人类干预

旋钮 C · 老本领要护住吗？

这是一个帮助记忆的粗分类，不是严格判据。真实方法往往同时用多个招式。

01一张地铁图：四条线 + 一个对照组

起点都是同一个预训练 VLA，终点是 2026 年的“能在真机上持续变好”。每条线代表一种“改动位置”。站名后面的年份是关键论文或工作出现的时间。

整模型：改全部，最强也最贵 生成过程内：冻结大部分，改去噪 残差：冻结 VLA，只加修正项 RL token / 蒸馏：把 VLA 压成可训练的小接口
记忆钩子：地铁图的站名虽然按时间排，但真正要记的是“线”。线决定了你要改哪里，站只是这条线上的代表作。

02七站故事：从“会模仿”到“能持续变好”

每站都按同一个骨架读：遇到什么问题 → 怎么绕 → 付出什么代价 → 留给下一站什么。

S1
2023–2024 · 起点

模仿示范：VLA 能做事，但天花板是示范

问题行为克隆只会复刻示范，示范里没有的失败恢复，模型根本学不到。
办法把大规模示范喂给预训练 VLM（RT-2、OpenVLA 一路下来），靠数据量堆能力。
代价示范越多越贵；模型一旦偏离训练分布，没有机制让它自己纠正。
留下“能不能让机器人自己试、自己学”成了下一步的问题。
相关：VLA 发展史 · OpenVLA vs π 系列
S2
2025 上半年 · 第一次把 RL 搬进 VLA

直接在仿真里用 PPO / GRPO 训整个 VLA

问题示范有上限，而 VLA 在仿真里能大批量试错。
办法把语言模型里成熟的策略梯度（PPO、GRPO）搬到动作序列上，VLA-RL 一类工作先证明了这条路能通。
代价要算 log 概率，计算贵；仿真和真机的差距（sim-to-real）还没解决。
留下“整模型 RL 真的能上真机吗？”
S3
2025 · 把 flow 的采样过程变成可以算 RL 的东西

流匹配不好算 log π：先把去噪链变成 MDP

问题flow/扩散的动作是从噪声一步步去噪出来的，没有现成的 log 概率，PPO 的 ratio 没法算。
办法把每个去噪步看作一个高斯策略：ReinFlow、πRL 等在去噪步里加可学习或可控的噪声，让 log π 可解。πRL 只训练约 3 亿参数的动作专家，冻结 VLM。
代价噪声调得不好，探索会乱；去噪链一长，信用分配更难。
留下“能不能不改模型、只在噪声上做文章？”
相关概念：去噪链 MDP，流匹配，动作专家。
S4
2025 · 冻结 VLA，只学一个修正量

残差策略：VLA 不动，外面套一层修正

问题整模型 RL 太贵，也怕把 VLA 原本会的东西忘掉。
办法冻结 VLA，学一个小的残差策略去修正它的动作。Policy Decorator、PLD、ConRFT 这类工作多是单步残差。Object-Centric RL 更进一步，用物体位姿作为观测，在纯仿真里训练后零样本上真机（成功率 42%→76%，见精读页）。
代价残差只能修局部；长时程任务里，信用分配仍然难。
留下“能不能把 VLA 的整体能力压缩成一个小接口，只训练这个接口？”
S5
2025–2026 · 两条分支：RL token 与 RL-100

把 VLA 压成一个 token；或者先离线 RL 再蒸馏

RL token从冻结 VLA 里抽出一个紧凑的 RL token，在它上面训练轻量 actor-critic，几小时真机数据就能精调毫米级精度的任务。见 RL Token 精读 和 漫画分镜版。
RL-100先用模仿学习打底，再做带 OPE 把关的迭代离线 RL，最后用一致性蒸馏压成单步策略。八项真机任务报告 100%（1000/1000）。见 精读页。
代价RL token 要求 VLA 结构可以“抽出表示”；RL-100 的算力大头在离线迭代。
留下“真机数据能不能直接当 RL 的主力，而不是仿真？”
S6
2025.11 · π*0.6 / RECAP

离线 RL 也能让大模型学会“从经验里改”

问题在线 RL 在真机上探索风险大、样本贵。
办法RECAP 用价值函数估计每一步的优势，把示范、模型自己的尝试、人类纠正全部喂进去，用优势条件化策略抽取。论文报告吞吐超过 2 倍，困难任务失败率约减半（公司一方数据）。见 π0.6 精读。
代价依赖价值函数的质量；人类干预仍是重要信号源。
留下“部署之后的经验，能不能回流到下一代通用模型？”
概念：RECAP，优势，稀疏奖励。
S7
2026.04 · π0.7

经验蒸馏：一个通用模型吃下多个专家的经验

问题每个任务各训一个专家，既贵又不通用。
办法公司报告 π0.7 把 RECAP 阶段积累的经验蒸馏进通用模型，在咖啡、叠衣服、组装盒子等任务上接近各自的专门模型，并能完成训练中未见过的任务（一方数据，待独立复现）。见 π0.7 学习卡。
代价蒸馏会不会把专家的边角能力磨平，目前缺独立评估。
留下“持续学习”从单任务走向“整个机队一起学”。
S8
2026 年 5–9 月 · 今天的前沿（arXiv 预印本）

在线、多机、不忘、看失败：四个新问题

机队在线学习多台机器人边部署边回传经验，共享一个通用策略（arXiv 2605.00416，Learning While Deploying）。
任务坍塌在线 PPO 微调 flow VLA 时，平均成功率看似正常，单个任务却可能被学坏；有工作提出用不确定性门控探索噪声来抑制（arXiv 2609.28838）。
稀疏结果只有整回合成败时，用分层优势加权做在线微调（arXiv 2606.17043）。
无奖励偏好FlowPRO 用偏好优化代替奖励与 critic，直接微调 flow 动作头（arXiv 2606.05468）。
实时性在线 RL 也要满足推理延迟，有工作专门研究实时 VLA 的 RL 训练（arXiv 2609.18207）。
以上为预印本摘要层面的梳理，数字未逐篇核实。整体脉络可参考 方法全景对比。

04四组拉扯：每条路线都在和它们打交道

不用记方法名，记住这四组拉扯，就能判断一篇新论文站在哪里。

⚖️

探索 ↔ 安全

多试才能学会，但真机上乱试会摔东西、损耗硬件。

对策：把探索限制在 VLA 能生成的动作里（噪声空间），或用人类干预兜底（HIL 系列）。

🧭

信用分配 ↔ 动作块长度

一个动作块 50 步，成败要归到哪一步？

对策：块级 RL（动作块当作一个动作）、优势加权、残差只修局部。

🎯

奖励 ↔ 人力

真机奖励很难写，人工标注又贵。

对策：稀疏成败 + 人类干预、学习型奖励分类器、偏好优化（FlowPRO 一类）。

🧠

学新 ↔ 不忘旧

在线更新一多，原本会的任务就会被冲掉，平均分却看不出来。

对策：冻结大部分参数，KL 或参考策略锚定，按任务而不是按平均分来监控。

05站在 2026 年 10 月的位置

结论先写：强化学习已经能在真机上让 VLA 变好，但“持续、稳定、多机、不忘”还没有解决。

已经比较清楚的
  • 整模型 RL 能提升能力，但要靠离线经验或仿真，真机在线试错仍贵。
  • 冻结大模型、只训练小接口（残差、RL token）是最经济的路线，适合单任务精调。
  • 经验可以从部署中回流，并被蒸馏进通用模型（RECAP → π0.7 一方报告）。
仍然开放的
  • 多任务同时在线学习时，如何避免某个任务悄悄退化（任务坍塌）。
  • 奖励与成败信号只在回合末尾出现时，如何做高效的信用分配。
  • 仿真与真机之间的差距，是否可以靠世界模型或合成数据弥合（如 VLA-RFT 一类工作）。
  • 推理延迟、动作块长度与 RL 的更新频率如何协调。

注：π0.7、RECAP 的性能数字来自公司或报告的一方数据；2026 年的多数论文是 arXiv 预印本，本页只做路线层面的梳理，不替代原文。

还没解决的问题，可以当作研究入口

Q · 坍塌怎么早发现？设计按任务拆分的监控指标，而不是只看平均成功率。
Q · 长时程怎么分配功劳？在动作块与回合之间找到合适的优势粒度。
Q · 机队数据怎么共享？不同机器人、不同任务的经验如何加权，又不互相干扰。
Q · 不改模型能走多远？只调噪声或残差，在哪些任务上会碰到上限。

06自测：能不能不看答案说出来？

先自己想，再展开。

为什么 flow VLA 的 PPO 不能直接用？

PPO 需要动作的概率比（ratio），而 flow 的动作是经过多步去噪从噪声生成的，没有现成的 log 概率。πRL、ReinFlow 等把去噪步当作高斯策略，才让 log π 可算。

残差路线和 RL token 路线有什么相同和不同？

相同：都冻结大部分 VLA，只训练小模块，计算省、不易忘本。不同：残差直接修正动作，RL token 则把 VLA 压成一个可训练的表示，再在它上面做 actor-critic。

RECAP 为什么能用“离线”做出效果？

因为它不需要每一步都在线试错：价值函数对已有的成功、失败、人类纠正数据估计优势，策略按优势条件化抽取。在线部署只负责持续产生新的数据。
