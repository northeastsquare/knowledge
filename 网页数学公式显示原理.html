网页数学公式显示原理

深入理解 KaTeX、MathJax、预渲染三种方案：工作原理、性能对比、如何选择

核心问题

浏览器只认 HTML/CSS/JavaScript，但数学公式通常用 LaTeX 写成（如 \frac{1}{2}）。如何让浏览器显示出标准数学书籍里的样式？

$$f(x) = \frac{\lambda^k \cdot x^{k-1} \cdot e^{-\lambda x}}{\Gamma(k)}$$

这个漂亮的公式，背后经历了什么？

三种解决方案

方案 1：预渲染

构建时转换，静态 HTML

  • ✅ 加载最快
  • ✅ 不依赖 JS
  • ✅ SEO 友好
  • ❌ 文件巨大
  • ❌ 需要构建工具
  • ❌ 维护成本高

方案 2：KaTeX 自动渲染

客户端实时转换，快速

  • ✅ 源文件小
  • ✅ 渲染速度快
  • ✅ 维护简单
  • ❌ 需要下载 JS
  • ❌ 不支持极复杂公式

方案 3：MathJax

客户端实时转换，全能

  • ✅ 支持所有 LaTeX
  • ✅ 源文件小
  • ✅ 功能最强
  • ❌ 渲染较慢
  • ❌ 文件更大 (~600KB)

方案 1：预渲染（概率分布博物馆用的）

什么是预渲染？

在生成 HTML 文件时，就把数学公式转换成完整的 HTML 标签。用户打开页面看到的已经是渲染好的样式，不需要运行 JavaScript。

工作流程

1
写 LaTeX 源码
在某个工具或脚本中写公式：\frac{1}{\beta}
2
构建时转换
运行 Node.js 脚本，调用 KaTeX API 把 LaTeX 转成 HTML
3
生成巨大的 HTML
一个简单的分式变成几百字节的嵌套 span 标签
4
上传到 GitHub
HTML 文件可能 400KB+，但用户打开就是最终效果

HTML 对比示例

$$f(x) = \frac{1}{\beta}$$
展开后 ~800 字节 
<span class="katex">
  <span class="katex-mathml">...</span>
  <span class="katex-html">
    <span class="base">
      <span class="mord mathnormal">f</span>
      <span class="mopen">(</span>
      <span class="mord mathnormal">x</span>
      <span class="mclose">)</span>
      <span class="mspace">...</span>
      <span class="mrel">=</span>
      <span class="mspace">...</span>
      <span class="mord">
        <span class="mfrac">
          <span class="vlist-t vlist-t2">
            <span class="vlist-r">
              <span class="vlist">
                <!-- 分子 -->
                <span class="mord">1</span>
                <!-- 分数线 -->
                <span class="frac-line"></span>
                <!-- 分母 -->
                <span class="mord mathnormal">β</span>
              </span>
            </span>
          </span>
        </span>
      </span>
    </span>
  </span>
</span>

如何实现？

build.js 
const katex = require('katex');
const fs = require('fs');

// 读取模板
let html = fs.readFileSync('template.html', 'utf8');

// 找到所有公式并转换
html = html.replace(/\$\$(.*?)\$\$/g, (match, latex) => {
  return katex.renderToString(latex, {
    displayMode: true,
    throwOnError: false
  });
});

// 写入最终 HTML
fs.writeFileSync('output.html', html);
⚠️ 为什么概率分布博物馆用这个？
因为那个页面有 17 个分布，每个分布有多个公式，还有 SVG 图表。预渲染后文件虽然大（400KB），但加载后完全不需要 JS 计算，打开就能看到最终效果，对复杂页面更稳定。

方案 2：KaTeX 自动渲染（推荐）

什么是自动渲染？

在 HTML 中写简单的 LaTeX 文本（如 $$f(x) = \frac{1}{\beta}$$），浏览器加载页面时，KaTeX 的 JS 找到这些公式，实时转换成 HTML。

工作流程

1
写 HTML 源码
直接在 HTML 中写 LaTeX：<p>$$f(x) = \frac{1}{\beta}$$</p>
2
上传到 GitHub
HTML 文件很小，只有几十 KB
3
用户打开页面
浏览器下载 HTML，看到原始的 $$...$$ 文本
4
加载 KaTeX JS（从 CDN）
浏览器从 jsdelivr.net 下载 katex.min.js (~200KB，会缓存）
5
自动查找和渲染
JS 运行：找到所有 $$ 和 $，转换成 HTML
6
用户看到漂亮公式
LaTeX 文本被替换成渲染好的数学符号

完整代码示例

your-page.html 
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>我的数学笔记</title>

  <!-- 1. 引入 KaTeX CSS -->
  <link rel="stylesheet"
    href="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.css">
</head>
<body>

  <h1>Gamma 分布</h1>

  <!-- 2. 直接写 LaTeX -->
  <p>密度函数：</p>
  <div>
    $$f(t) = \frac{\lambda^k \cdot t^{k-1} \cdot e^{-\lambda t}}{(k-1)!}$$
  </div>

  <p>行内公式：均值是 $\frac{k}{\lambda}$</p>

  <!-- 3. 页面底部引入 KaTeX JS -->
  <script defer
    src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js">
  </script>

  <!-- 4. 引入自动渲染插件 -->
  <script defer
    src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/contrib/auto-render.min.js"
    onload="renderMathInElement(document.body, {
      delimiters: [
        {left: '$$', right: '$$', display: true},
        {left: '$', right: '$', display: false}
      ],
      throwOnError: false
    });">
  </script>

</body>
</html>

为什么能在 GitHub Pages 工作？

GitHub Pages 就是静态文件托管，把你的 HTML/CSS/JS 文件原样放在服务器上。

  1. 用户访问 https://你的用户名.github.io/页面.html
  2. 浏览器从 GitHub 下载你的 HTML 文件
  3. HTML 里引用了 CDN 的 KaTeX JS（cdn.jsdelivr.net）
  4. 浏览器再从 CDN 下载 KaTeX JS
  5. 所有计算都在用户浏览器里完成，不需要服务器端运行代码

关键：GitHub Pages 不需要处理任何公式，它只是提供 HTML 文件；公式渲染发生在用户浏览器中。

性能数据

指标 数值 说明
HTML 文件大小 ~50KB 包含 LaTeX 文本
KaTeX JS 大小 ~200KB 首次加载，之后浏览器缓存
渲染速度 ~10ms 渲染一个中等复杂公式
首次加载总时间 ~0.5s 取决于网络速度
再次访问 ~0.1s JS 已缓存，只下载 HTML

方案 3：MathJax

什么是 MathJax？

另一个数学公式渲染库，比 KaTeX 更强大但更慢。也是客户端实时渲染（工作原理类似 KaTeX 自动渲染）。

使用示例

使用 MathJax 
<!DOCTYPE html>
<html>
<head>
  <!-- 配置 MathJax -->
  <script>
  MathJax = {
    tex: {
      inlineMath: [['$', '$']],
      displayMath: [['$$', '$$']]
    }
  };
  </script>

  <!-- 引入 MathJax -->
  <script async
    src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js">
  </script>
</head>
<body>

  <p>公式：$$\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}$$</p>

</body>
</html>

KaTeX vs MathJax 详细对比

特性 KaTeX MathJax
速度 🚀 非常快（~10ms/公式） 🐢 较慢（~50-100ms/公式）
文件大小 ~200KB ~600KB
LaTeX 覆盖率 ~90% 常用命令 ~99% 所有命令
渲染质量 优秀 优秀
浏览器兼容性 现代浏览器 所有浏览器（包括 IE11）
维护状态 活跃 活跃
GitHub Stars ~18k ~10k

何时选择 MathJax？

  • 需要极复杂的 LaTeX 命令（如自定义宏、复杂的多行公式）
  • 已有内容用了 MathJax 语法（迁移成本高）
  • 需要兼容老旧浏览器（IE11）
💡 本知识库的选择
π0 论文解读等页面用 MathJax，Gamma 分布、Beta 分布等新页面用 KaTeX。两者可以共存，只要不在同一个页面同时使用（会冲突）。

常见问题

Q1: 为什么页面加载时公式会闪一下？

A: 这是 KaTeX/MathJax 自动渲染的正常现象。页面先显示原始 LaTeX 文本，JS 加载完成后再替换成渲染好的公式。

解决方法：

  • 方法 1：给公式容器加 CSS：visibility: hidden;，渲染完成后用 JS 设为 visible
  • 方法 2：使用预渲染（但失去灵活性）
  • 方法 3：接受这个瞬间的闪烁（大多数网站的做法）

Q2: CDN 在中国大陆访问慢怎么办？

A: jsdelivr.net 在国内有 CDN 节点，通常很快。如果确实慢，可以：

  • 方法 1：下载 KaTeX 到本地，放在 assets/katex/ 目录
  • 方法 2：使用国内 CDN（如 unpkg.com 或 staticfile.org）

Q3: 能不能同时用 KaTeX 和 MathJax？

A: 不推荐在同一个页面同时使用，会冲突。但不同页面可以用不同的库（如你的知识库现状）。

Q4: GitHub Pages 有什么限制？

A: GitHub Pages 的限制：

  • 仓库大小限制：1GB（数学公式网页通常远低于此）
  • 单个文件限制：100MB（即使预渲染的 HTML 也不会这么大）
  • 带宽限制：每月 100GB（个人网站足够）
  • 核心限制：只能托管静态文件，不能运行服务器端代码（但这对数学公式不是问题）

Q5: 公式渲染失败怎么办？

A: 常见原因：

  • LaTeX 语法错误：检查括号是否匹配、命令是否拼写正确
  • 特殊字符未转义：在 HTML 中 < 要写成 &lt;
  • KaTeX 不支持某些高级命令：换用 MathJax 或简化公式
  • JS 加载失败：检查网络连接和 CDN 是否可访问

设置 throwOnError: false 可以让渲染失败的公式显示为红色错误文本，而不是阻塞整个页面。

Q6: 本地能渲染，GitHub Pages 不能渲染？

A: 这是最常见的坑！可能的原因：

症状：本地打开 file:///D:/knowledge/page.html 正常，GitHub Pages 上显示不出来

原因：路径写法不对

❌ 错误写法（本地能用，GitHub 不行）：
<script src="/assets/katex/katex.min.js"></script>
// GitHub 会找 https://你的用户名.github.io/assets/katex/...
// 但实际是 https://你的用户名.github.io/仓库名/assets/katex/...

✅ 正确写法 1：相对路径
<script src="assets/katex/katex.min.js"></script>

✅ 正确写法 2：使用 CDN（推荐）
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>

症状：浏览器控制台显示 "Mixed Content" 错误

原因：GitHub Pages 用 HTTPS，但你引用了 HTTP 的资源

❌ 错误写法：
<script src="http://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>
// 注意是 http:// 不是 https://

✅ 正确写法：
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>
// 或者省略协议（自动匹配）：
<script src="//cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>

症状：用 CDN 的能渲染，用本地文件的不行

原因：本地的 assets/katex/ 文件夹忘记 commit 或 push 了

# 检查文件是否在 GitHub 上
# 访问：https://github.com/你的用户名/仓库名/tree/main/assets/katex
# 能看到文件吗？看不到就是没上传

# 解决方法：
git add assets/katex/
git commit -m "Add KaTeX assets"
git push

症状：明明 add 了，但 GitHub 上没有

原因：.gitignore 把 KaTeX 文件排除了

# 检查 .gitignore
cat .gitignore

# 如果看到这样的规则：
node_modules/
dist/
*.min.js

# 那么 katex.min.js 会被忽略！

# 解决方法 1：移除规则
# 解决方法 2：强制添加
git add -f assets/katex/katex.min.js

症状：访问 GitHub Pages URL 显示 404

原因：仓库的 Pages 功能没有开启

  1. 进入仓库 Settings
  2. 左侧找到 "Pages"
  3. Source 选择 "Deploy from a branch"
  4. Branch 选择 "main" 或 "master"，目录选 "/ (root)"
  5. 点 Save，等待 1-2 分钟
  6. 刷新页面，会显示网站 URL

症状：改了代码，GitHub Pages 还是显示旧的

原因：浏览器缓存了旧版本

# 解决方法：
1. 按 Ctrl + Shift + R (Windows/Linux) 或 Cmd + Shift + R (Mac) 强制刷新
2. 或者打开浏览器开发者工具（F12），右键刷新按钮，选 "清空缓存并硬性重新加载"
3. 或者打开隐私浏览模式测试

如何排查？

  1. 打开浏览器开发者工具（F12）
  2. 切换到 "Console" 标签页
  3. 刷新页面，看有没有报错：
    • ❌ Failed to load resource: 404 → 文件路径错误或文件不存在
    • ❌ Mixed Content → HTTP/HTTPS 混用
    • ❌ renderMathInElement is not defined → JS 加载顺序错误或未加载
    • ✅ 没有报错但公式不显示 → 可能是分隔符配置错误
  4. 切换到 "Network" 标签页，刷新，检查 KaTeX 的 JS/CSS 文件是否成功加载（状态码应该是 200）

Q7: CDN 被墙了怎么办？

A: jsdelivr.net 在中国大陆通常可用，但有时会被短暂屏蔽。备选方案：


<link rel="stylesheet" href="https://unpkg.com/katex@0.16.9/dist/katex.min.css">
<script src="https://unpkg.com/katex@0.16.9/dist/katex.min.js"></script>


<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/KaTeX/0.16.9/katex.min.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/KaTeX/0.16.9/katex.min.js"></script>


<link rel="stylesheet" href="assets/katex/katex.min.css">
<script src="assets/katex/katex.min.js"></script>

进阶：本地化 KaTeX（不依赖 CDN）

为什么本地化？

  • 完全离线可用（不需要网络）
  • 加载速度更可控（不依赖 CDN）
  • 避免 CDN 服务中断

步骤

# 方法 1: 直接下载
# 访问 https://github.com/KaTeX/KaTeX/releases
# 下载 katex.zip，解压到 assets/katex/

# 方法 2: 使用 npm
npm install katex
cp -r node_modules/katex/dist assets/katex/

修改引用路径

<!-- CSS -->
<link rel="stylesheet" href="assets/katex/katex.min.css">

<!-- JS -->
<script defer src="assets/katex/katex.min.js"></script>
<script defer src="assets/katex/contrib/auto-render.min.js"
  onload="...">
</script>
💡 你的概率分布博物馆页面
已经本地化了 KaTeX CSS（assets/katex/katex.min.css），但使用的是预渲染 HTML，所以不需要 JS 文件。
