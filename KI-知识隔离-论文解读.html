让新手的梯度只走一半

知识隔离（Knowledge Insulation）· 一篇关于“梯度往哪儿流”的论文

这篇论文只做了一件事：切断一条梯度通路。难的是搞清楚两件事——为什么只切这一条，切完之后骨干还能不能学会机器人该学的东西。

Knowledge Insulating Vision-Language-Action Models: Train Fast, Run Fast, Generalize Better
Driess, Springenberg, Ichter, Yu, Li-Bell, Pertsch, Ren, Walke, Vuong, Shi, Levine · Physical Intelligence · 2025.05
本页依据论文正文（10 页主文）整理，附录未逐条核对。
01 · 先看一个画面

一位老师，一个新人，一本共享的笔记

把 VLA 想成一栋楼。楼上住着一位老师：它是预训练过的 VLM（约 3B 的 PaliGemma 骨干），读过海量文字、看过海量图片，会说话，也认得东西。楼下来了一个新人：一个 300M 的动作专家，参数随机初始化，手还不稳，但它要负责写出连续的机器人动作。

新人不是凭空干活。它要读老师写下的笔记——骨干在每一层算出的 key 和 value。这就是 动作专家的工作方式：自己不看图、不读字，只从骨干那里借表征。

问题出在回流。新人写错了一个动作，误差会沿着它读笔记的那条路倒着传回去，改的恰恰是老师的笔记本身。新人还没学会，老师先被改坏了。

这个“倒着传回去”不是比喻。训练时，损失对动作专家参数的梯度，要经过注意力层穿回骨干的 K、V，再穿进骨干的全部权重。论文里的整个故事，都是这一条反向路径的故事。
02 · 病理

梯度是信使，也可能是污染源

在标准的 π0 训练里，骨干和动作专家之间有两条通道：前向的 K/V（读），以及反向的梯度（写）。直觉上人们更关注前向，因为它是“知识从 VLM 流向动作”的那一条。论文指出，反向那条路同样存在，而且在新专家刚初始化时，它最危险。

标准 π0：K/V 向前，梯度向后，两条线都在。KI：只保留前向读取，反向那条线被 stop-gradient 切断。

论文的诊断可以概括成一句话：随机初始化的连续输出模块，一边没学会，一边就把预训练得来的语言能力冲掉了。它表现为两个症状：训练慢，以及语言跟随变差。图 2 的例子很直观——同一条指令“把勺子放进垃圾桶”，π0 直接去抓了别的垃圾。

这里有一个容易漏掉的问题：为什么不直接冻结骨干？后面第 05 节会回到这个问题。

03 · 手术

三刀，各切一处

论文没有只切一刀。它同时做了三件事，每一件都在解决“老师需要什么信号、新人该怎么接入”的一部分问题。

  • 用离散动作 token 训练骨干，而不是只用连续动作

    把动作先用 FAST 压缩成离散 token，让骨干做普通的 next-token 预测。这些 token 和文字共用同一个输出口，不需要为动作新加一个 head。

    关键在于：这个训练信号不经过新专家的权重。它是骨干本来就熟悉的形式，所以能替代被切断的那条梯度，继续教骨干如何表示机器人任务。论文也比较了朴素的逐 bin 离散化：它仍比纯连续训练好，但不如 FAST；按步长 5 稀疏子采样的版本又比稠密版本好。

  • 混入通用 VLM 数据：co-training

    训练集里不只有机器人数据，还加入图像描述（caption）、视觉问答（VQA）、框选定位，以及机器人的规划数据。它们不含连续动作，只为了让骨干别忘了怎么看图说话。

    作者在通才模型实验里发现：去掉 VLM 数据后，联合训练的语言跟随下降最明显。他们的解释是，这些数据防止了对预训练表征的“灾难性干扰”。

  • Stop-gradient + 注意力掩码：把信息流改成单向

    专家读骨干的 K/V 时，套一层 sg（stop-gradient）。骨干的注意力行里，动作 token 的贡献为零；FAST token 与连续动作 token 之间互相不可见。

    注意：切断的是回传，不是读取。专家依然完整地看到骨干的表征，只是不能改它。信息从老师流向新人，不再逆流。

训练时三者同时进行，共用一次前向：同一个序列里同时有文字、FAST token 和连续动作，靠掩码分开。推理时则只留下专家和几步 flow 积分，FAST token 和文字输出都不生成。

行 → 能看见 ↓骨干 tokensFAST tokens动作专家 tokens
骨干（图像、文字、状态）✓✗✗
FAST（离散动作）✓✓ 只看前面的✗
动作专家（连续动作）✓ 只读，K/V 经 sg✗✓

按论文式 (5)(6)：骨干对专家不可见；专家对骨干只读；FAST 与专家彼此不可见。信息只有一个方向：骨干 → 专家。

表里最反直觉的是“骨干看不见专家，但专家能读骨干”。这不是对称的注意力，是一扇单向门。
04 · 条件

这个切法什么时候才成立

论文里有一句很关键、却容易被略过的话：stop-gradient 只在一个条件下是“合理的”——骨干同时被训练去直接预测动作。

这个条件把一切连了起来。切断回传之后，骨干还要学会动作，它的学习信号只能来自离散 token。如果骨干不预测动作，那么切断之后，骨干就根本得不到任何关于机器人的训练，专家也只能在一块不适应机器人的表征上硬学。所以三刀不是三个独立的技巧，而是一个成立的组合：切断回传 ⇔ 离散动作预测替代回传。

CONCEPT · 知识隔离

训练 VLA 时，让骨干通过离散动作 token 与通用视觉语言数据学习；让连续输出的动作专家只读取骨干、不反向更新骨干。这样，新加入的随机参数不会冲掉预训练知识，同时仍保留连续动作的快速推理。

05 · 为什么是隔离，不是冻结

问题不在骨干能不能动，而在骨干被谁推动

冻结骨干看起来最安全：预训练知识一根毛都不碰。论文的实验说它不行，原因是 VLM 的表征没有见过机器人数据，冻住之后表征不够用。论文里冻结骨干的基线表现很差（图 8 中为 0%）。

所以问题的形状是：骨干既要学机器人，又不能被新人的梯度拖着走。三种选择的取舍如下：

冻结骨干不学机器人，表征不够用，成功率很低。
放开让专家的梯度回传，骨干学得动，但语言被冲掉，训练也慢。
隔离骨干由离散 token 和 VLM 数据训练，专家不回写。学得动，语言保住，训练快。

隔离的要点在于：它不是“限制骨干能不能变”，而是决定骨干由哪种信号来改。同一个骨干，换了信号来源，结果完全不同。这也是我读完这篇论文最想记住的一点：信号的来源比信号的强弱更重要。

07 · 容易读错的地方

四处容易误解

① KI 不是 π0.5 的两阶段。π0.5 先用 FAST 预训练，再加入随机专家做后训练（两阶段）。KI 的做法是把两步合进同一个阶段。论文自己的说法是：它“形式化”了 π0.5，并把它扩展成单阶段配方。
② stop-gradient 不等于“专家看不见骨干”。专家全程读取骨干的 K/V。切断的只是回传。
③ α = 1 的理由。作者说，因为专家的损失作用在一组独立的权重上，所以不需要用权重去平衡两个损失。我的理解是：两个损失不争同一组参数，平衡系数也就失去了“平衡”的意义。
④ 离散 token 只存在于训练里。论文原话是：它只在训练时用作表征学习的目标。推理时它不存在。它是搭脚手架用的，楼盖好了就拆掉。
08 · 我的追问

读完之后留下的几个问题

以下是我自己的推测，论文没有讨论，所以我把它们当作假设，而不是结论。

问题 A · 骨干的动作表示有没有天花板？FAST 的 DCT 加量化是有损的。骨干学到的是“有损的动作语言”，它对力度、速度这类连续细节的表示，是否会被这个离散化误差卡住？论文证明了 FAST 比朴素分词好，但没有量化有损带来的上限。
问题 B · 单向门的代价。专家不能告诉骨干“你该看哪里”。如果动作误差能反馈回视觉注意力，模型也许会学到更主动的看法。stop-gradient 把这条路堵死了。论文把语言跟随“仍然不完美”归因于训练数据里的相关性；单向隔离是不是也是原因之一，论文没有排除。
问题 C · 同一个工具，三种用途。stop-gradient 在知识库的其他地方出现过好几次，用途各不相同：Qwen-VLA 的价值头里，它用来保护骨干，免得价值信号冲坏表征；RL-100 的一致性蒸馏里，它让 teacher 在被 RL 改进的同时仍然稳定；RL Token 的重建里，它把原特征当作常数。把它们放在一起看，三者共享的是同一个问题：谁有资格改谁。梯度不是越多越好。

10 · 自测

三个问题，看看你是不是真的懂

如果把 stop-gradient 换成“专家完全不看骨干，只看自己的输入”，会怎样？

专家失去了骨干的表征，就失去了 VLM 知识迁移的通道，等于丢掉了论文最核心的收益。它不会因此更稳定，只会更弱。论文的 stop-gradient 切的是回传，专家仍然读取骨干，这一点不能丢。

为什么离散 token 能替代被切断的梯度，而连续动作的梯度不行？

论文的回答是：离散 token 的学习信号“不受动作专家未初始化权重的影响”。它通过和文字共享的输出口训练，形式上和 VLM 的预训练任务同构；连续动作的梯度则来自一个随机初始化的新 head，噪声大，方向也不可靠。

哪个消融最能说明，问题不只在“加了离散分支”，还在“两条分支能不能互相看见”？

HybridVLA 式的设置：自回归 token 可以看到连续输入。在“items in drawer”任务上，它明显差于论文的掩码设计。同样是两种动作表示，只因为可见性不同，结果就差很多。
