让新手的梯度只走一半

知识隔离（Knowledge Insulation）· 一篇关于“梯度往哪儿流”的论文

这篇论文的核心是切断一条梯度通路。但只切这一刀是不够的：切完之后，骨干还得从别处学会机器人该学的东西。所以真正要搞懂的是两个问题：为什么只切这一条，以及切完靠什么补上。

01 · 先看一个画面

一位老师，一个新人，一本共享的笔记

把 VLA 想成一栋楼。楼上住着一位老师：它是预训练过的 PaliGemma（2B 语言模型加视觉编码器，图 1 标作 3B），读过海量文字、看过海量图片，会说话，也认得东西。楼下来了一个新人：一个 300M 的动作专家，参数随机初始化，手还不稳，但它要负责写出连续的机器人动作。

新人不直接处理图像和文字 token。它在每一层通过注意力，读取老师在这一层算出的 key 和 value。这就是 动作专家的工作方式。两者能逐层对接，是因为它们深度相同（18 层）、注意力头维度相同（256），只是专家更窄（宽 1024，骨干宽 2048）。附录 B

问题出在回流。新人写错了一个动作，误差会沿着它读笔记的那条路倒着传回去，改的恰恰是老师的笔记本身。新人还没学会，老师先被改坏了。

“倒着传回去”不是比喻。训练时，流匹配损失的梯度经过专家的注意力，穿回骨干的 K、V 投影，再穿进骨干的全部权重。这篇论文讲的，就是这一条反向路径。
02 · 病理

梯度是信使，也可能是污染源

在 π0 的训练方式里，骨干和动作专家之间有两条通道：前向的 K/V（读），以及反向的梯度（写）。直觉上人们更关注前向，因为它是“知识从 VLM 流向动作”的那一条。论文指出，反向那条路同样存在，而且在新专家刚初始化时最危险。

π0：K/V 向前，梯度向后，两条线都在。KI：只保留前向读取，反向那条线被 stop-gradient 切断。

症状有两个：训练慢，以及语言跟随变差。图 2 的例子很直观：指令是“把勺子收进垃圾桶”，π0 不理指令，抓起了另一件垃圾。

注意论文的用词。它说语言跟随变差“presumably due to gradient interference”，即“推测是梯度干扰造成的”。这是一个假设，下一节看它靠什么支撑。

03 · 证据链

凭什么说是梯度在捣乱

论文没有直接测量梯度或表征的变化，它的证据都是行为层面的：几组对照实验，每组只改一个地方。把它们排在一起，结论才站得住。

让梯度回流的，语言都差

“items in drawer” 任务（图 4b）里，凡是让专家梯度进入骨干的方案（π0、不切梯度的联合训练），语言跟随都明显变差。π0-FAST 没有专家，语言跟随反而保持得好。

新增的随机参数越少，伤害越小

Transfusion 直接用骨干权重去噪连续动作，唯一新增的随机参数是动作投影层。它的语言跟随好于带专家的 π0（图 5）。

不切梯度时，VLM 数据最能救场

通才模型上，去掉 VLM 数据对“不切梯度的联合训练”打击最大（图 6a）。作者的解释是：没有隔离时，这些数据格外需要，用来避免对预训练表征的灾难性干扰。

排除一个混淆因素：状态表示

π0 用连续状态，KI 默认用文本状态。附录图 10 把两种状态表示都试了：KI 两种都行，π0 两种都差。所以差距不是状态表示带来的。顺带一个旁证：“特殊 token 状态”同样是随机初始化的新嵌入，它的表现最差。

作者的措辞是这些结果“strongly support the hypothesis”（强有力地支持这一假设）。我同意这个强度：证据很一致，但仍是间接的。

04 · 手术

一刀切断，两处补上

论文同时做了三件事。第 III 件是切断，前两件是补偿：切断之后，骨干需要别的信号来学机器人。

  • 联合训练：骨干也预测离散动作

    把动作用 FAST 压缩成离散 token，让骨干做普通的 next-token 预测，同时专家用流匹配预测连续动作。FAST token 和文字共用同一个输出口，不需要新加 head。

    论文原话：离散 token 提供了一个“不受动作专家未初始化权重影响”的替代学习信号。它是骨干预训练时就熟悉的任务形式，所以能接替被切断的那条梯度，继续教骨干表示机器人任务。消融里，换成朴素的逐 bin 离散化：仍比纯连续训练好，但不如 FAST；按步长 5 稀疏采样又比稠密版本好。

  • VLM 数据联训（co-training）

    训练集里加入不含动作的数据：图像描述（CapsFusion、COCO）、视觉问答（Cambrian-7M、PixMo、VQAv2）、物体框选定位，以及带语言标注的机器人规划数据。附录 A.3

    它的作用是让骨干在适配机器人时，别忘了怎么看图说话。它和 I、III 不同：去掉它，KI 仍然成立，只是任务完成度略降、新物体泛化变差（见第 06 节）。

  • Stop-gradient + 注意力掩码：信息只能单向流动

    专家读骨干的 K/V 时，套一层 sg（stop-gradient）：前向照常计算，反向在这里截断。

    切断的是回传，不是读取。专家依然完整地看到骨干的表征，只是不能改它。

为什么只需要在一处套 sg

论文式 (5)(6) 把注意力概率按“谁看谁”拆成四块。骨干看专家的那一块，被掩码直接置零：

看 骨干 tokens
看 专家 tokens
骨干行
Qb·Kb → Vb
0（不可见）
专家行
Qa·sg(Kb) → sg(Vb)
Qa·Ka → Va

右上角是 0，说明骨干的前向计算根本不依赖专家。那么专家的损失想影响骨干参数，只剩左下角一条路：经过 Kb、Vb。在这里套上 sg，就把唯一的通路堵死了。专家自己的 Qa、Ka、Va 照常接收梯度。

依据附录 B：前缀内部是完整的双向注意力；FAST 看前缀并按顺序自回归；专家看前缀和彼此，不看 FAST，“以避免两种动作表示之间的信息泄漏”。没有任何骨干 token 看专家。

FAST 和专家互相不可见，两个方向各有理由。附录给出的理由是防止信息泄漏，展开来是：

专家不能看 FAST：训练时 FAST token 是 teacher forcing 的真值，专家看得到就能直接“抄答案”；而推理时根本不生成 FAST token，训练与推理会对不上。
FAST 不能看专家：专家的输入是带噪的真实动作，噪声小时几乎就是答案。骨干的离散预测要是能偷看它，就会去抄，不再学习有用的表征。HybridVLA 恰好允许自回归 token 看连续输入，它在抽屉任务上明显变差，这与此一致。

损失怎么合在一起

式 (4)：L = 交叉熵(文字 + FAST token) + α · 流匹配损失，两项各带掩码，所以一个 batch 里可以混合纯 VLM 样本、纯动作样本、语言加动作样本。训练时三类 token 共用一次前向，靠掩码分开；推理时只跑专家的几步 flow 积分，不生成 FAST token。

流匹配的写法：aτ = τ·a + (1−τ)·ω，网络预测 ω − a。在这个约定下 τ→0 是纯噪声，所以论文说时间步分布“偏向低 τ”，等价于 π0 页所说的“偏向高噪声段”，只是 τ 的方向记法相反。分布为 Beta((s−τ)/s; 1.5, 1)，s = 0.999。附录 B
05 · 条件

这一刀什么时候才能切

论文里有一句关键、却容易被略过的话：stop-gradient 是合理的，当且仅当骨干同时被训练去直接预测动作（原文 “if and only if”）。

反过来想就明白了：如果骨干不预测动作，切断之后它就收不到任何关于机器人的信号，效果接近冻结骨干。论文测过冻结，图 4a 和图 8 里都是 0%。所以 I 和 III 是一对：切断回传 ⇔ 用离散动作预测接替回传，缺一个都不成立。II 是加强项，不是前提。

CONCEPT · 知识隔离

训练 VLA 时，骨干通过离散动作 token（以及通用视觉语言数据）学习；连续输出的动作专家只读取骨干、不反向更新骨干。这样，新加入的随机参数不会冲掉预训练知识，同时仍保留连续动作的快速推理。

为什么是隔离，不是冻结

冻结看起来最安全，但 VLM 预训练时没见过机器人数据，冻住的表征不够用。骨干必须学，但不能被新人的梯度推着走。把论文里的几种选择排在一起：

冻结骨干骨干不学机器人。抽屉、叠衣任务 0%。
π0：只有流损失专家梯度回流。语言跟随差；达到同等成绩约需 7.5× 训练步数。
联合训练，不切梯度有 FAST 信号，但专家梯度也回流。有 VLM 数据时语言尚可，没有时语言差；通才模型的任务完成度下降。
KI骨干只由离散 token 与 VLM 数据塑造，专家只读。各项最好或接近最好。

差别不在“骨干能不能变”，而在骨干由哪种信号来改。同一个骨干，换了信号来源，结果完全不同。

08 · 容易读错的地方

六处容易误解

① KI 不是 π0.5 的两阶段。π0.5 先只用 FAST 训练，再在后训练里加入随机初始化的专家，一起训练。KI 从一开始就把两种动作表示放在同一个阶段里训练。论文的说法是：它把 π0.5 的做法“形式化”，并扩展成单阶段配方。
② stop-gradient 不等于“专家看不见骨干”。专家全程读取骨干每一层的 K/V，切断的只是回传。
③ α = 1 不是调参调出来的。论文说，有了 sg，流匹配损失作用在“一组独立的权重”上，所以直接设 α = 1。展开来看：交叉熵只更新骨干（骨干看不见专家），流匹配损失只更新专家（回传被切断），两项损失没有共享参数，不存在谁压过谁。α 只相当于缩放专家这一侧的梯度。
若优化器是 Adam 类（论文没写明），按参数归一化的更新会把这种整体缩放几乎抵消掉，α 取多少影响就更小了。
④ 离散 token 只在训练时存在。论文原话：自回归目标“只在训练时作为表征学习的目标”。推理时不生成 FAST token。它是脚手架，楼盖好了就拆掉。
⑤ “知识隔离”的范围比 stop-gradient 大。论文正文有时把切梯度和混 VLM 数据都叫作“knowledge insulation techniques”（见第 06 节）。读别的论文说“沿用 KI”时，要看它指的是哪一部分。
⑥ 联合训练不切梯度，并不是一无是处。它有 FAST 信号，加上 VLM 数据后语言跟随也不错，在专才的餐桌清理任务上“也表现良好”。它的问题主要出现在通才模型的任务完成度上，以及没有 VLM 数据时的语言跟随上。
09 · 我的追问

读完之后留下的几个问题

这些是我自己的推测，论文没有讨论，所以当作假设，而不是结论。

问题 A · “保住了 VLM 知识”是怎么测的？论文标题说泛化更好，摘要说保住知识，但它从没在 VQA、图像描述这类 VLM 基准上评测训练后的骨干。它测的是机器人层面的语言跟随和新物体泛化。这是合理的代理指标，但“知识是否真的没丢”并没有被直接测量。
问题 B · 骨干的动作表示有没有天花板？FAST 的 DCT 加量化是有损的。骨干学的是“有损的动作语言”，它对力度、速度这类细节的表示，会不会被离散误差卡住？LIBERO-10 上 KI 和 π0 几乎一样（85.8 对 85.2），说明长时程上限主要不在隔离与否。
问题 C · 单向门的代价。专家不能告诉骨干“你该看哪里”。如果动作误差能反馈给视觉表征，模型也许会学到更贴合动作的看法。论文把语言跟随“仍远不完美”归因于训练数据中的相关性；单向隔离是不是也有一份，论文没有排除。
问题 D · 同一个工具，几种用途。stop-gradient 在知识库其他地方也出现过：Qwen-VLA 的价值头对骨干隐状态做 sg，免得价值信号改坏表征；RL-100 的一致性蒸馏用 sg，让 teacher 被 RL 改进的同时仍能当目标；RL Token 重建时对原特征做 sg，把它当作常数目标。它们背后是同一个问题：谁有资格改谁。

11 · 自测

四个问题，看看你是不是真的懂

如果把 stop-gradient 换成“专家完全不看骨干”，会怎样？

专家失去了骨干的表征，也就失去了 VLM 知识迁移的通道，丢掉了这篇论文最核心的收益。它不会因此更稳，只会更弱。KI 切的是回传，读取必须保留。

为什么只在专家读骨干 K/V 的地方套 sg，就足以隔离整个骨干？

因为骨干行看专家列的注意力被掩码置零，骨干的前向计算完全不依赖专家。专家损失影响骨干参数的唯一路径，就是专家行里的 Kb 和 Vb。堵住这一处，就全部堵住了。

去掉离散动作预测、只保留 stop-gradient，会怎样？

骨干收不到任何机器人信号，效果接近冻结骨干，而冻结在论文里是 0%。这正是论文说 sg “当且仅当骨干同时预测动作时才合理”的原因。

HybridVLA 的结果能证明“FAST 偷看连续动作”有害吗？

只能算支持，不能算证明。论文把它的失败归因于注意力设置（自回归 token 能看连续输入），而且最接近的对照“不切梯度、无 VLM 数据的联合训练”被描述为“自回归 token 看不到连续输入的 HybridVLA 变体”。但 HybridVLA 用的是朴素分词，联合训练用的是 FAST，两者不止注意力一处不同。
