Qwen-VLA：统一任务、环境与机器人构型的视觉-语言-动作建模

统一任务、环境与机器人构型的 VLA，实现跨形态泛化。

论文Qwen-VLA: Unifying Vision-Language-Action Modeling across Tasks, Environments, and Robot Embodiments
机构Qwen（阿里巴巴）
arXiv2605.30280v2
主题VLA · 多构型泛化

它解决的问题

具身智能长期被切成一个个专用模型：操作模型只管桌面或灵巧手，导航模型只围绕室内 waypoint/动作预测，每个模型都绑死一种任务族、一种机器人构型、一种评测设定。结果是能力碎片化，跨任务、跨环境、跨构型几乎不迁移，也没法像通用视觉-语言预训练那样规模化具身学习。

这些任务表面差异极大：

  • 操作要预测末端位姿 / 关节角 / 夹爪开合 / 灵巧手构型；
  • 导航要预测 waypoint 或离散移动决策；
  • 人类自我中心视频给的是手腕 + 手部轨迹，而非机器人控制信号。

它们在观测格式、控制频率、预测视野、动作维度、评测协议上全都不同。但作者指出它们共享同一种计算结构：智能体都要「以视觉观测 + 语言指令 + 构型约束为条件，预测与任务在物理和语义上对齐的未来动作/轨迹」。

一句话：把「操作、导航、轨迹预测」看成同一个「动作-轨迹条件预测」问题的不同形态，用一个 VLA 统一建模。

方法主线

跨本体（cross-embodiment）指同一模型适应不同机器人构型及其控制语义，例如不同臂型、关节维度或控制频率。这里用构型提示和统一动作表征实现；它与“仿真到真机”的域迁移是不同的维度。五步把异构具身任务收进一个模型：

  1. 统一问题形式化：所有任务写成 p(yt:t+H-1 | ot, x, e, z)——给定视觉 ot、指令 x、构型描述 e、任务 id z，预测未来 H 步动作/轨迹序列。
  2. 双模块架构：Qwen3.5-4B 原生多模态骨干（ViT 空间合并 + 混合注意力）负责理解与推理；外挂一个 DiT 流匹配动作专家（约 1.15B 参数）负责细粒度连续动作生成。
  3. 构型感知提示（embodiment-aware prompt）：每个样本前拼一段文本，描述「机器人平台、臂型、控制频率、预测视野」。这是模型获知控制语义的唯一接口，换机器人只换文本，不动架构。
  4. 统一动作/轨迹表征：用 H×K 张量 + 二值掩码把不同控制模式（末端/关节/夹爪/灵巧手/导航 waypoint）塞进同一套 DiT，各数据集保留原生控制约定。
  5. 四阶段渐进训练：T2A（纯文本训动作解码器）→ CPT（解冻双模块、视觉接地）→ SFT（双分支对齐）→ RL（PPO+GAE 直接优化闭环成功率）。

训练或运行方式

在预训练好的 Qwen3.5 VLM 之上，作者用四阶段渐进训练，动机是「压缩—解压」视角：语言指令只占几个 token，对应动作却可能上百个高维关节值，衔接这个维度差是一个结构化「解压」问题。

  • Stage I · T2A（text-to-action DiT 预训练）：冻结 VLM，只训 DiT，输入仅文本 + 构型提示，刻意不给图像。让解码器先学会「语言→动作」解压、建立结构化动作先验，避免一开始就为无视觉无关的解码器学习浪费算力。
  • Stage II · CPT（续训）：解冻两个模块，在异构混合数据（真实 + 仿真 + 导航 + 人类自我中心 + 视觉语言）上联合训练，把动作先验接地到视觉观测。
  • Stage III · SFT（监督微调）：从 CPT 分两条支路——① 多任务 SFT（VQA + 空间接地 + 操作 + 导航，构型/任务均衡采样）；② 真机遥操作 SFT（ALOHA），验证跨域先验能否迁移到物理硬件。
  • Stage IV · RL（强化学习）：从 SFT 出发，PPO + GAE，稀疏二值成功奖励，只在 SimplerEnv 单个仿真环境采样，产出最终模型 Qwen-VLA-Instruct。

训练目标 = 流匹配动作损失 + 视觉语言下一 token 损失加权（L = αactLact + αvlLvl），每个 mini-batch 按固定比例混合所有任务族。RL 阶段关键细节：

  • 动作块 H=16；128 个并行环境；每次迭代 8×128 步 → 8192 个 transition chunk；rollout 温度 τ=1.0，评测降到 0.6。
  • 价值头直接挂在 VLM 骨干上（mean-pool + 线性），对 VLM hidden states 做 stop-gradient，价值头用独立学习率 1e-4（约为 actor 的 20 倍），快速收敛而策略更新保守。
  • 流匹配的 log-prob：把确定性概率流 ODE 转成 SDE（每个 Euler 步注入受控噪声），使每步转移成为显式高斯，可解析算重要性比，无需数值积分。

关键消融结论

  • T2A 数据配比：20% 合成 + 80% 真实最优（71.1%），比不做 T2A（60.9%）高 +10.2pp；纯合成 64.1%、纯真实 51.0%。
  • 全序列 > 分块预测（+4.9pp @10% 合成）；T2A 阶段给图像反而掉 2.9pp（会走视觉捷径，稀释语言-动作映射）。
  • 时间步分布：T2A 用 Sigmoid-Normal（向中间噪声层倾斜）+ SFT 用 Beta 最佳（71.1%）；反过来 Beta@T2A 掉 5.7pp。
  • T2A 时长：2000 步封顶（71.1%），40000 步过拟合掉到 60.4%。
  • VL 共训：在 RoboCasa +4.9pp、RoboTwin +4.6pp——视觉语言数据不打架，还在细粒度识别/组合指令解析上明显增益。
  • 动作空间投影：Multi-MLP / 拼接 / Zero-Padding 三方案差距 <1.2%，Zero-Padding 最省参数，被选为默认。
  • 显式本体状态（关节角）收益甚微（Easy +0.7pp、Hard +1.3pp），故默认只用视觉 + 语言。

我真正学到的内容

  • 异构具身任务可归约为同一问题：操作、导航、轨迹预测、人类自我中心动作，都是「以视觉 + 语言 + 构型为条件预测未来动作/轨迹」，统一形式化本身就是最大贡献。
  • 「压缩—解压」训练视角：语言指令是任务意图的紧凑编码，动作轨迹是高频高维信号；先用 T2A 学「语言→动作解压器」，再接地视觉，训练既稳又省——这是把随机初始化解码器与强预训练骨干"不对称冷启动"问题化解掉的关键。
  • 构型提示是零成本的多构型接口：换机器人 = 换一段文本，不改架构、不加输出头；RL 微调也能零样本迁移到域外构型。
  • 视觉语言数据与动作数据共训不冲突，还在难任务上补语义——「通用 VL 理解」不是负担，是具身泛化的底座。
  • 显式本体状态没那么重要：多视角视觉 + 相对位移动作已经隐含了机器人当前构型，加关节角输入收益微弱。

可复用设计

  • embodiment-aware prompt 模板：固定句式 The robot is {tag} with {arms}... The control frequency is {FPS} Hz. Please predict the next {chunk} control actions...，把平台/臂型/频率/视野写进提示，作为唯一平台接口。
  • Zero-Padding + 二值掩码统一动作空间：H×K 张量，短动作右补零，掩码挡住零填充位不参与梯度；一套 DiT 处理所有控制模式，参数最少且不掉点。
  • 分位数归一化：每数据集每维度取 1st/99th 百分位线性映射到 [-1,1]，跨构型去尺度、保留相对运动结构。
  • 两阶段细粒度动作描述：粗看视频提动作序列 → 稠密采样帧再精修（接触点/空间关系/轨迹），加人工校正，产出稠密语言监督。
  • PPO 接入流匹配的 log-prob 技巧：ODE→SDE 注入受控噪声，使转移成为显式高斯、可解析求重要性比；价值头 stop-gradient + 独立更大学习率。
  • T2A 时间步分布策略：无视觉条件时用 Sigmoid-Normal 向中间噪声层倾斜，有骨干条件后用 Beta。

疑问与风险

  • 数据规模仍是硬约束：具身动作数据远小于、也远不如视觉语言数据多样，长尾物体/环境/构型与接触密集交互的鲁棒性存疑（作者自己也承认）。
  • 联合训练有优化 trade-off：动作导向训练会轻微回退部分纯视觉语言与导航评测——多目标之间如何更好地平衡/课程化仍是开放问题。
  • 评测偏短视距、benchmark 驱动：长时、易失败、需持续恢复的真实部署尚未验证。
  • 真机 OOD 内部不均衡：ALOHA OOD 里 Position 泛化只有 53.8%（Background/Instruction 却 80.8%/84.6%），「空间位置」仍是相对短板。
  • RL 只在单一仿真环境采样：其 OOD 泛化依赖「任务成功语义与渲染无关」的假设，这一机制的边界未充分论证。

后续动作

  • 补概念：流匹配（flow matching）的概率流 ODE→SDE 化求 log-prob 的推导；DiT 的 AdaLN 与多段 RoPE。
  • 读 ROBOINF 数据引擎博客，理解合成 VLA 数据的生成管道（场景 → 任务 → 成功轨迹 + 域随机化）。
  • 在自己 VLA 上做最小改动实验：加 embodiment prompt + 掩码统一动作空间，看能否零成本支持第二个构型。
  • 复现 T2A：先文本后视觉的预训练能否带来可测量的稳定性/样本效率提升。
