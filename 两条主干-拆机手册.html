拆机手册A vs B内部资料

原理页里那两条「主干」，到底是什么两台机器
拆开看

原理对比页开头说：所有 on-policy 方法来自策略梯度定理，所有 off-policy / 离线方法来自 Bellman 方程。这句话是整张图的分水岭，但它把两台构造完全不同的机器压缩成了一行字。这一页把它们拆开摆在台面上 —— 每台机器解决什么问题、靠什么零件转动、哪里必然会坏。

§0 · 拆之前：它们在抢同一份工作

两台机器的输入输出完全一样

不管哪条主干，最终交付的产品都只有一个：一个策略 π —— 看到状态 s，输出该做什么动作 a，使长期回报最大。区别在于「怎么造出这个 π」。

状态 s
图像+关节角 ──→ 策略 π ──→ 动作 a ──→ 奖励 r + 新状态 s' ↺

这个循环转到底，拿到的总回报是 R = r₀ + γr₁ + γ²r₂ + …（γ<1，越远的奖励折价越多）。两条主干都想把 R 的期望做大。

Trunk A

造法一：直接拧概率

不评价世界，只盯住自己的输出分布。哪个动作事后看还不错，就把它的概率往上拧一点；哪个差，往下拧。

我不知道世界值多少钱，
我只知道这次干得比平均好，那就多干。

  • 零件：一个可微的 π_θ
  • 核心问题：拧多大力（= 优势 A 怎么估）
  • 产物：PPO / GRPO / DAPO / Reinforce++
Trunk B

造法二：先标一张价目表

不碰概率，先给每个「状态+动作」标价：在 s 做 a，往后总共能赚多少。表标好了，策略就是查表挑最贵的。

策略是价目表的副产品，
我真正在学的是那张表。

  • 零件：一个 Q(s,a) 估值网络（critic）
  • 核心问题：表会虚高（= 那个 max 的祸）
  • 产物：SAC / CrossQ / RLPD / DSRL / IQL
§1 · 主干 A · 策略梯度定理

一台「拧概率」的机器

目标写出来很朴素：J(θ) = E[总回报]，想让它变大，就沿梯度 ∇J(θ) 走。麻烦在于——回报是「采样」出来的，而采样这一步没法直接求导。策略梯度定理就是绕过这一步的那个结论：

∇J(θ) = E[ ∇log π_θ(a|s) · A(s,a) ]

整台机器只有两个零件，而且分工极其干净：

零件 1 · 方向盘

∇log π_θ(a|s)

「要让这个动作 a 的概率变大，参数该往哪边挪」——这是一个纯数学问题，自动微分白给，不需要任何设计。它只管方向，不管该不该走。

零件 2 · 油门/刹车

A(s,a) · 优势

一个标量。正就顺着方向盘踩油门（概率调高），负就反向踩（概率调低），绝对值是踩多深。它是唯一需要猜的东西，所有算法的差别都在这。

看懂这一行，主干 A 就通了：

梯度 = 方向（送来的） × 力度（要自己估的）。所以 PPO / GRPO / DAPO / Reinforce++ 这些名字，全都不是不同的理论，只是同一台机器上换了「力度表」的不同型号。

力度为什么不能直接用「总回报 R」？

最原始的想法（REINFORCE）就是拿 R 当力度。问题用三个数就能看出来。假设某状态下三个动作，跑完拿到的回报分别是 10、11、12：

用 R 当力度: a₁ ← +10 踩油门 a₂ ← +11 踩油门 a₃ ← +12 踩油门 三个动作的概率全都被推高 —— 可它们的概率加起来必须是 1！ 最后只靠 10/11/12 的细微差别分出胜负，学得极慢、抖得极凶。 减掉平均 11: a₁ ← −1 刹车 a₂ ← 0 不动 a₃ ← +1 油门 「比平均好多少」才是有效信号。这就是优势 A，减掉的那个数叫 baseline。

关键性质：减 baseline 不改变梯度的期望（无偏），只减小方差。所以它是纯白赚的。整条主干 A 的全部工程量，就是「baseline / 优势用什么算」：

PPO → 养一个 critic 学 V(s)，用 GAE 算 A 准，但要多一个几十亿参数的网络 GRPO → 同一状态采一组，用组内均值当 baseline 省掉 critic，但要求能重复采样 Reinforce++→ 回报里再减掉 KL 累积，然后全局归一化 不裁剪，方差更大 OPD → 直接用 teacher 的 logprob 之差当 A 连奖励都不要了 STEAM → 从演示的时间顺序自监督出 A 连奖励都不存在
实验 1 · baseline 怎么把「全都推高」掰成「有升有降」拖动 →

三个动作，回报固定为 10 / 11 / 12。拖动 baseline，看每个动作被推还是被拉：

b = 0.0

这台机器有两个死穴

死穴 1 · 数据用一次就废（on-policy）。那个期望 E[·] 是在当前策略 π_θ 下取的。策略一更新，旧数据就来自「另一个策略」，统计上不再算数。所以每批 rollout 只能训一两步就得扔——样本效率的天花板就在这里。裁剪（PPO）、KL 惩罚都是在回答同一个问题：在数据还没完全作废之前，最多能走多远。

死穴 2 · 必须能算出 log π。高斯策略白给。但流匹配 / 扩散策略是「噪声→动作」的确定性 ODE，log π 根本写不出来。主干 A 直接卡死——这就是原理页里家族 ③（SAC-Flow / DSRL / πRL）存在的全部理由。

§2 · 主干 B · Bellman 方程

一台「标价目表」的机器

这台机器完全不走梯度上升。它先学一张价目表 Q(s,a)：在状态 s 下做动作 a，往后一共能赚多少。表准了，策略就免费了——查表，挑最贵的那个动作。

经验 (s,a,r,s') ──→ 拟合价目表 Q ──→ π = argmax Q

价目表必须自己跟自己对得上

怎么学这张表？不需要跑完整条轨迹。因为一张正确的价目表必然满足一条自洽条件——今天的价，等于今天的钱加上明天最好的价（打个折）：

Q(s,a) = r + γ · maxa' Q(s', a')

于是训练方式变成：把右边算出来当「标准答案」，让左边去拟合它。反复迭代直到不动为止（不动点迭代）。这个「用自己算出的答案训练自己」的把戏叫 bootstrapping，是主干 B 的心脏。

实验 2 · 价值是怎么一格一格「渗」回来的bootstrapping

五格走廊，只有走到最右边才给 +1 奖励，γ=0.9。全表从 0 开始，每点一次做一轮 Bellman 更新：

奖励只在最右边。第一轮只有它的邻居学到东西。

这个动画解释了一件事：

信息是每轮只往回传一格的。所以主干 B 的「收敛慢」不是玄学，而是结构性的。也正因如此，CrossQ 才会说 target 网络虽然稳，但它人为延迟了价值传播，是样本效率的隐形税——它拖慢的就是这个渗透过程。

回报：数据可以永久复用

看那条自洽式子的右边：r + γ max Q(s',a')。它只用到 (s, a, r, s') —— 完全不在乎这条经验是谁采的。

主干 A: E[...] 必须在当前 π下取 → 换了策略，旧数据作废 on-policy 主干 B: 自洽条件与采集者无关 → 旧数据永远有效，塞进 replay buffer 反复用 off-policy

这就是样本效率差一个量级的来源，也是真机实验几乎只能走主干 B 的原因：你没有一亿次试错的预算。顺带还能直接吃别人采的数据（离线数据集、人类演示）。

代价：那个 max 是万恶之源

表是估出来的，必然带噪声。而 max 干的事情是——在一堆带噪的数字里挑最大的那个。它不是在挑最好的动作，它是在挑运气最好的误差。

实验 3 · max 如何无中生有地造出乐观overestimation

四个动作的真实价值都是 0。网络每次估的时候各自带一点随机噪声。max 会挑中红色那根：

采样 0 次 · 四个数的平均 ≈ 0.00（真值 0，没毛病）· max 的平均 ≈ 0.00（真值也该是 0！）

这个偏差不会自己抵消，它会复利。虚高的 Q(s',a') 被当成「标准答案」写回 Q(s,a)，下一轮又被 max 挑中、再虚高一层。误差沿着 Bellman 迭代系统性放大，最后价值爆炸、策略去追一个根本不存在的高分动作。

纯离线时更惨：max 会去问「数据里从没出现过的动作」值多少，而网络对这些动作的输出纯属幻觉，且幻觉一定偏高（不高就不会被 max 选中）。没有环境交互能来打假。

于是有了一整排「反乐观」补丁

SAC → 双 Q 取小 故意制造负偏差，对冲正偏差 SAC → target 网络缓慢跟随 切断「自己的误差立刻喂给自己」的回路 SAC → 加熵项把 max 变「软」 最优策略从尖峰变成玻尔兹曼分布 RLPD → critic 上加 LayerNorm 限制网络在没见过的动作上输出任意大的值 STEAM → 集成取 worst-of-N 和双 Q 取小是同一个思想 IQL → 干脆不取 max 用期望回归逼近高分位，全程不问 OOD 动作

原理页里那句「家族 ② 和 ⑤ 的所有花招，本质都是在跟这个 max 搏斗」，说的就是上面这六行。

§3 · 并排对照

分水岭在哪一刀切下去

同一列上下对读，就能看出两台机器为什么长成完全不同的样子。

对比项主干 A · 策略梯度主干 B · Bellman
学的是什么直接学策略 π_θ 的参数学价值表 Q，策略是副产品
数学工具梯度上升（往上爬）不动点迭代（反复自洽）
核心公式∇J = E[∇log π · A]Q = r + γ max Q'
要自己设计的优势 A 怎么估怎么防 max 虚高
数据能否复用不能。策略一变旧数据作废能，永久复用（replay buffer）
样本效率低（靠仿真器堆数量）高一个量级（真机可行）
要不要 criticPPO 要；GRPO 用组内均值省掉必须要，critic 就是主体
要不要 log π必须（扩散策略直接卡死）需要（最大熵版本里的 −α log π）
探索从哪来策略自身的随机性熵项显式奖励探索
典型坏法方差大、熵坍缩、步子迈太大崩掉价值高估 → 价值爆炸
代表算法PPO · GRPO · DAPO · Reinforce++ · πRLSAC · CrossQ · RLPD · DSRL · IQL

原理页那五个家族，各自在补哪个洞

① on-policy 主干 A → 补「A 怎么估 + 能走多远」 PPO/GRPO/DAPO/R++ ② off-policy 最大熵 主干 B → 补「max 会虚高」 SAC/CrossQ/RLPD ③ 流 / 噪声空间 A 和 B → 补「log π 算不出来」 SAC-Flow/DSRL/πRL ④ 表示与蒸馏 主干 A → 换掉「A 的来源」本身 RLT / OPD ⑤ 离线 主干 B → 补「没有环境能来打假」 IQL/RECAP/STEAM

换句话说：家族 ① 和 ④ 是主干 A 的后代，② 和 ⑤ 是主干 B 的后代，③ 是为了让扩散策略能接上这两条主干而造的转接头。原理页 15 行表格，就是这五个分支的展开。

§4 · 现场速认

看到一个新算法，三秒判断它姓 A 还是姓 B

  • 论文里出现 clip、KL、ratio r = π_new/π_old → 主干 A。它正在操心「步子别迈太大」。
  • 出现 replay buffer、target network、双 Q 取小、UTD → 主干 B。它正在操心「表别虚高」。
  • 出现 GAE、baseline、组内归一化 → 主干 A，而且在改力度表。
  • 出现 α log π（熵项）→ 主干 B 的最大熵分支，顺带把探索内建进目标。
  • 号称「不需要 critic」→ 几乎一定是 主干 A，并且用了某种便宜 baseline 顶替 V(s)。
  • 号称「能用离线数据 / 真机样本效率高」→ 主干 B，接着去找它防高估的那一招。
  • 主角是扩散 / 流匹配策略 → 先去看它怎么处理 log π（构造出来？还是换空间绕开？），再判断它挂在哪条主干上。
整页压成三句话：

主干 A 是拧概率的机器，方向白给，全部难点在「这次该拧多大力」——代价是数据用一次就废。
主干 B 是标价目表的机器，表一准策略就白给，数据能永久复用——代价是表里那个 max 会自己把自己吹起来。
你在 RLinf 里看到的 15 个算法，没有第三条路，全是这两台机器换零件。
