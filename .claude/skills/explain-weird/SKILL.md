# 卡住的概念 → 一页怪风格讲解

## 步骤

1. **定位卡点**：用户卡在哪句话、哪个公式。`grep -n` 找到原页面对应段落，局部读。用一句话写出「读者缺的是哪一步」。
2. **选风格**：读 `../paper-to-page/references/style-registry.md`，挑一个没用过的视觉隐喻，并让它和概念有点关系（等待 → 时钟，分布 → 球星卡数据栏）。用完追加到登记表。
3. **写页面**（一次写完，单文件）：
   - 开头：用户原来的疑问原样放上去，再给一句话答案。
   - 先讲一个**小数字例子**（3–5 个数能手算的那种），再给公式，再解释每个符号。
   - **2–3 个 JS 实验**让机制动起来：滑块改参数看曲线变、按钮一步步执行算法、随机采样看统计规律浮现。写完用 node 抽出计算函数跑一遍，确认正文里说的数字和实验输出一致。
   - 结尾：「回到原文」链接到原页面的具体锚点；2–3 道小题（`<details>` 折叠答案）。
   - 遵守站点约定：`concepts.css`、页尾 `nav.js`、相对路径、公式用本地 `assets/katex`、手机宽度不横向滚动。
4. **互链**：在原页面卡点处加一个小链接「看不懂？→ 新页面」；新页面加到 `nav.js` 和 `index.html`。
5. **校验**：`node scripts/check-concept-links.mjs`，浏览器打开看实验能动。
6. 提交并推送 `origin master`。

## 写作

- 大白话，短句，一段一件事。
- 怪的是外观，内容要准确：数字、公式、结论和原论文一致。
- 不复述原页面已讲清的部分，只补缺的那一步。
