1

痛点：会干活，但"最后一毫米"在磨蹭Introduction

一句话版本

现在的 VLA（视觉-语言-动作模型）拿来就能干几十种活：抓、放、叠衣服、拧螺丝。但真正决定成败的，往往是插进去那一下——网线口对不对正、螺丝刀尖有没有卡进螺丝头、拉链扣能不能穿过那个窄缝。

模型在这几秒里的表现很典型：靠近 → 犹豫 → 退回来 → 再试一次，来回磨蹭好几轮才成。论文管这叫 probing（试探）行为。

为什么会这样 因为 VLA 是模仿人类遥操作数据学出来的。遥操作数据里本来就有人类的迟疑、停顿、重试；而且高精度任务的示教数据又少又不一致。模仿学习的天花板 = 数据的质量天花板，所以光加数据是治不好"慢"的。

那就让它自己练：强化学习（RL）

RL 的逻辑很朴素：真机上反复试，成功给 +1，失败给 0，自己摸索出比人更快更稳的招。但真机 RL 有个铁一样的约束——每一次尝试都要花真实时间，还磨损硬件。论文的目标定得很具体：几小时内（有的任务甚至几十分钟）必须看到提升。

2

两条老路，各有各的死穴Related Work 的取舍

路线 A：直接用 RL 训整个 VLA

几十亿参数一起更新。理论上最彻底，实际上：
• 每步梯度都很贵
• 需要巨量交互样本
• 几小时内根本训不出东西

太慢！

路线 B：抛开 VLA，训个小模型

像 HIL-SERL 那样，ResNet 编码器 + 小 actor-critic。几小时能学会，但：
• 丢掉了 VLA 的泛化与常识
• 等于从零开始学这个任务

白瞎了预训练！

论文的问题意识 能不能既吃到 VLA 的泛化能力，又保留小模型的学习速度？——办法是分工：冻住的 VLA 负责"看懂世界 + 给建议"，一个小网络负责"把最难那几秒改得更好"。
3

招式一：RL Token，把大模型的理解压成一颗药丸Sec. IV-A

问题：VLA 内部的特征太多太杂

一个 transformer VLA 每层都有几百个 token、每个 2048 维。你不知道该喂哪些给 RL。全喂进去，小网络会被维度淹死；随便挑几个，又可能丢掉关键信息。

解法：加一个"复述考试"

在 VLA 最后一层的 token 序列 z₁..z_M 后面追加一个可学习的特殊 token <rl>，一起过一个小的 encoder transformer。取 <rl> 那个位置的输出，就是 RL Token（1×2048）。

关键在于怎么训它：再接一个 decoder，只给它这一颗 RL Token，要求它把原来所有 token 全部重建出来（自回归、L2 损失、对原特征 stop-gradient）。

这就是经典的信息瓶颈：想通过考试，这颗 token 就必须把任务相关的信息尽量塞进去。训练时 VLA 本体是冻的（可选同时做一点监督微调），训完 VLA 和这个编解码器一起冻住。

实验 1：瓶颈有多窄，才还能"复述"得出来？

灰线 = VLA 原始特征；橙线 = 只靠瓶颈向量重建出来的结果。拖动瓶颈宽度，看重建误差怎么变。点"换一组特征"可以看不同样本。

要点：瓶颈越窄，重建越糊，但向量越"精炼"。论文选的是 1×2048——足够小到让两层 MLP 能在几分钟数据上学动，又足够大到装下任务相关结构。后面的消融会告诉你：换成 ImageNet 预训练的 ResNet-10 编码器，吞吐直接掉一半。

4

招式二：以"动作块"为单位，把记功距离缩短 10 倍chunked action

50Hz 是 RL 的噩梦

机器人以 50Hz 控制，一段"插网线"的关键阶段有 250~1000 步。奖励只在最后给一个 +1。如果 RL 按单步决策，价值函数得把这一个稀疏奖励沿着几百步一路往回传——这就是信用分配（credit assignment）难题，实际上传不动。

RLT 的做法：actor 一次输出 C=10 步的动作块（14 维 × 10 = 140 维动作），critic 也按块估值。有效决策步数一下砍到几十步。

顺带一个小技巧：虽然按 10 步一块决策，但每 2 步就抽样存一条 transition 进回放池，1 秒数据能榨出约 25 个训练样本。

先把记号钉死：s 和 x 不是一回事

这是全篇最容易晕的地方，也正是这篇论文的贡献所在。s 是物理世界的状态，x 是小网络透过 VLA 这块镜片看到的 s。

s（相机图像+本体感知） → 冻住的 VLA + 冻住的 encoder → z_rl（1×2048） → 拼上 sᵖ → x

机器人在 s 空间里真实转移，但学习全程发生在 x 空间里。论文写 z_rl(s) 就是在强调 RL Token 是状态的一个函数。消融里"去掉 RL Token"换成 ResNet-10，改的就是 s→x 这一步，s 本身没变。

记号含义维度
s世界真实状态：4 路相机 + 本体感知 + 语言原始高维
sᵖs 里的本体感知部分（关节位置/速度或末端位姿）几十维
z = f(s, ℓ)冻住的 VLA 末层的全部 token 嵌入M × 2048
z_rlRL Token：z 过小 encoder 后 <rl> 位置的输出1 × 2048
x = (z_rl, sᵖ)小网络实际看到的状态~2100 维
a_{1:C}动作块，10 步 × 14 维140 维
ãVLA 建议的参考动作块（喂给 actor 看的草稿）140 维
a'落点处从策略新采样的假想动作，只用来估值，不在机器人上执行140 维
Q(x, a)critic：2 层 MLP 隐层 256（螺丝任务 3 层 512）输出 1 标量
λEq.5 里拉住 actor、不许离 ã 太远的系数—

那这个 Q 到底哪来的？

Q 就是一个随机初始化的 2 层 MLP，输入 (x, a_{1:C}) 拼接，输出一个标量。论文明确写 actor 和 critic 都 from scratch 初始化。

所以训练刚开始，减法两边都是彻头彻尾的胡话——一个随机网络说"这状态值 0.37"，另一个说"下个状态值 0.52"，全无根据。它没一直胡话下去，靠两件事：

① r 是唯一的真相注入口。终点那格的 +1 是人类给的、真实的，那一格的目标里没有任何猜测成分，所以它第一个被拽准。然后邻居 bootstrap 它、邻居的邻居再 bootstrap 邻居……真相一跳一跳从终点往回扩散（下面那张图画的就是这个过程）。

② 目标那侧被冻住（target 网络 + detach）。每次更新里目标是个不动的靶子；若两侧都动，就会互相追着漂到"差值为 0 但全是 0"的退化解。论文还按 TD3 用两个 Q 取最小值，因为 bootstrap 天生倾向高估自己。

一句话：Q 不是算出来的，是被真实奖励反复拽出来的。它的可信度完全来自终点那些 +1。

但要命的是：r 几乎总是 0

论文的奖励设定极其稀疏——人类只在回合结束时标一次，成功 r_T=1，否则 0，中间全程没有任何奖励。把目标公式的 10 项展开就看清了（γ=0.97, C=10, 当前 Q=0.30，落点 target 网络给 0.50）：

Q̂ = γ⁰·r₁ + γ¹·r₂ + … + γ⁹·r₁₀ + γ¹⁰·Q_target
   = 0 + 0 + … + 0 + 0.7374 × 0.50 = 0.369 → δ = +0.069，略微上调

整个第一项全军覆没。对 99% 以上的 transition，目标里一点真相都没有，纯粹是"用猜测改进猜测"：

情况目标成分
非终点（绝大多数）Q̂ = γ^C · Q_target纯 bootstrap，零真相
终点（极少数）Q̂ = r = 1纯真相，零猜测

若第 10 步插进去了：Q̂ = γ⁹×1 = 0.760，δ = +0.46——大幅上调，而且不 bootstrap。

这个 r=0 才是全篇真正的难点，也一口气解释了论文所有设计动机：
• 必须用动作块 → 纯 bootstrap 的链条每多一环多一层误差，C=10 把链缩短 10 倍
• 必须双 Q 取最小 → 链条全是自我引用，高估会沿链放大
• 必须只练关键阶段 → 把片段拎出来练，r 到起点的距离短得多
• HIL-SERL 在 50Hz 下学不动 → 单步、几百步长、r 全是 0，信号传不过来

插播：TD3 是什么，RLT 借了它哪几件装备

TD3 = Twin Delayed Deep Deterministic policy gradient（Fujimoto et al. 2018，论文引用 [19]），是 DDPG 的修补版，专治一个顽疾：critic 系统性高估自己。

高估怎么来的：你总朝"看起来最好的动作"去 bootstrap，而 Q 是带噪声的网络，噪声里偏高的那些值会被优先选中、写进目标、下一轮又被 bootstrap——误差正反馈放大，Q 膨胀到离谱，actor 追着一个虚高指标走，训练崩掉。上面说的"99% 纯 bootstrap"让这个风险更大。

TD3 的招做法RLT 用了吗
Twin 双 Q养两个独立 critic，算目标时取两者最小值。两边高估噪声不一致，取 min 就偏保守——宁可低估（学得慢）也别高估（会崩）✅ 附录明说
Delayed 延迟更新actor 更新频率低于 critic，等 critic 稳了再动✅ 2 次 critic 配 1 次 actor
Target smoothing给目标动作加噪声，抹平 Q 的尖峰论文未提

还有个 TD3 之前就有、它也在用的东西：target 网络。上面那个 0.50 就是它给的——一份缓慢跟进的 critic 副本。要副本是因为：若用正在训练的 critic 自己算目标，靶子会跟着枪口一起动，容易发散。

要说准确：RLT 不是照搬 TD3。TD3 的 actor 是确定性策略，RLT 的 actor 是高斯策略、还额外吃参考动作 ã。论文说自己建立在 SAC[17] / TD3[19] / SVG[34] 这一系之上，借的主要是 critic 那半边的机械装置。

实验 2：稀疏奖励往回传，块长决定要多久

先说清"TD 更新"是什么：TD = 时序差分。critic 要估"从这里开始未来能拿多少奖励"，但奖励只在最后给一个 +1。TD 的办法是不等结局，而是把 Q(现在) 往 即时奖励 + γ·Q(下一步) 拉近——用一个猜测去改进另一个猜测（bootstrap）。论文按块版本：Q̂ = Σγ^(t'-1)·r_t' + γ^C·Q_target(x')，先把块内 C 步的真实奖励加起来，再从 C 步之后的状态借估计。

"谁减谁"：δ = [r + γ^C·Q_target(x',a')] − Q_online(x, a_{1:C})，后一时刻的 Q（加上中间真实拿到的奖励）减去前一时刻的 Q。两处要注意：① 不是对称减法——目标那侧被 detach（论文按 TD3 用 target 网络算，还取两个 Q 的最小值防高估），梯度只进减数那侧，是单向拉拽；若两侧都给梯度，它们会互相靠拢漂到退化解。② 这两个 Q 是同一个 critic 在相邻时刻的自我评价，不是两个动作比大小——"时序差分"的名字就来自这里。目标之所以更可信，是因为掺了 r 这一粒真相；而终点那一格根本没有第二个 Q（回合结束不 bootstrap，目标就是纯 +1），它是整条链的锚点。

代个数（γ=0.97, C=10，当前 Q=0.30）：块内没成功、落点 target 网络给 0.50 → Q̂ = 0.97¹⁰×0.50 = 0.369，δ=+0.069，略微上调；块内插进去了 → Q̂ = 0.97⁹×1 = 0.760，δ=+0.46，大幅上调。δ 为负就是"实际不如预期"，下调。

关键后果就是下面这张图：一次 TD 更新，奖励信息只能往回移动"一跳"，而一跳的长度正好是 C。格子是一段任务的时间轴，最右端成功给 +1。每点一次按钮跑一轮更新，价值就往前渗透一跳。比较 C=1 和 C=10 各需要多少轮才能把信号传到起点——注意最终传到起点的数值是一样的，差的只是更新次数。

这就是论文里 HIL-SERL 和 PLD 两个单步基线在网线任务上学不动的直接原因：任务跨几百步、奖励又稀疏，单步 TD 根本传不回来。

补一句真实情况：现实中"一轮更新"不是这里这种整齐的全局扫描，而是从回放池采一个 batch 做一次梯度更新，每跳都带着神经网络逼近误差和采样噪声，跳数越多误差累积越狠。所以单步方法不只是"慢一点"，而是常常根本收敛不了。本 demo 用确定性回溯，展示的是每个 C 的最理想传播速度，真实差距比图上更悬殊。

招式三：抄着改，别从零猜reference action + BC 正则

actor 的输入里，直接塞进 VLA 的答案

RLT 的 actor 是个高斯策略 π(a|x, ã)：输入不只有状态 x =(RL Token, 关节/位姿)，还有 VLA 当前采样出的参考动作块 ã。相当于考试时允许看学霸的草稿，任务从"自己想答案"变成"把这份草稿改得更好"。

还有个隐藏好处：VLA 的动作分布是多模态的（有好几种可行做法），而高斯 actor 是单峰的。把采样出的 ã 传进来，等于顺手保留了"这次打算走哪条路"的模态信息。

损失函数里再拴一根绳

目标是 L(π) = −Q(x,a) + λ‖a − ã‖²：一边要 critic 打高分，一边被拉住不许离 VLA 太远。λ 就是"允许多大胆"的旋钮，精神上等价于 KL 正则的 RL。

但也不能让它变成复印机

只要既看着 ã 又被罚着靠近 ã，actor 很容易退化成直接照抄——尤其是 critic 还没学明白的早期。所以论文加了参考动作 dropout：训练时随机把 50% 的 ã 换成全零，逼 actor 保留一条"没有草稿也能作答"的独立通路；推理时 ã 总是给。

实验 3：λ 旋钮——保守得一无所获，激进到摔个稀烂

灰虚线是 VLA 参考动作的轨迹，橙线是 RLT 实际执行的。背景绿色越深 = critic 认为价值越高（右下角那片是"又快又准"的最优区）。拖 λ 看策略被拉到哪。

论文的消融结论正是这样：把 λ 设成 0（去掉 BC 正则）是所有消融里掉得最惨的一项——actor 失去约束，只靠 Q 的梯度在 140 维动作空间里乱撞。

完整流水线：人类当裁判，也当保险Algorithm 1 · Sec. V

按顺序读一遍这条流水线

① 备料：收 1~10 小时该任务的遥操作示教，微调 VLA + 训 RL Token（2000~10000 步梯度），然后全部冻住。

② 热身：先用 VLA 自己跑若干回合，把回放池填上，让 critic 有初始信号——RL 一开始就站在"已经会干活"的水平上。

③ 只练最难那一段：每个回合先由 VLA 执行简单部分，人类在关键阶段前把控制权交给 RL 策略。数据收集和记功都集中在这 5~20 秒。

④ 人类的两个角色：给稀疏的成功/失败标签（这就是全部奖励信号）；必要时接管遥操作，接管数据会替换掉参考动作存进回放池。

⑤ 更新：off-policy，回放池里 VLA 数据、RL 数据、人类接管数据混着用。UTD（更新/数据比）高达 5，每 2 次 critic 更新配 1 次 actor 更新，采集与训练异步跑。

⑥ 收尾自动化：最后再微调 VLA，让它学会预测"该交班了"（用人类的接管时机当标签），测试时就能自动切换。

整个流程图：16 格一圈，r 在第 ⑧ 格进来

灰虚线 = VLA 给 actor 的参考动作 ã（不经过 RL，直接旁路送过去）。最右侧虚线 = 循环回到 ⑤ 跑下一个动作块。橙色格子是 r 唯一的入口，绿色格子是唯一接收梯度的地方。

注意颜色的分布：橙只有 ⑧⑪⑫ 三格——r 进来、进目标、变成 δ；绿只有 ⑤⑬⑭⑮ 四格，是唯一会被梯度改动的部件。蓝的 ②③ 全程冻结，一个梯度都不走。这就是为什么几十分钟真机数据够用：真正在学的只有那两个小 MLP。

实验 5：r 怎么一路把整条链拽准（这次带采样噪声）

12 个动作块边界串成一条链，最右端成功给 +1。每个格子的数字就是 critic 当前的 Q 估计，初始是随机小值（模拟随机初始化的 MLP）。每点一次"采样一次更新"，随机抽一条 transition 做一次真实的 TD 更新（含学习率、含噪声），看 δ 怎么从终点开始把整条链拽准。

观察两件事：① 靠近终点的格子先变准，误差像波纹一样往左推——因为只有它们的目标里含真实的 r。② δ 一开始很大（学得猛），收敛后趋近 0（没东西可学了）。对比实验 2 的理想扫描，这里能看到真实训练的抖动。

一句话记住整个系统 冻住的大模型提供眼睛和草稿，一个两层 MLP（难任务用三层 512）在真机上练手，人类只负责说"这次算成功"和偶尔扶一把。

插网线沉孔内插接，位置和角度都得准，还必须"果断"插进去，犹豫就会卡在外壳上
插充电器厘米级对齐，但插头和插孔经常看不清，容易反复试探

整个任务 30~120 秒（1500~6000 控制步），关键阶段只占 5~20 秒（250~1000 步）。评估分两档：关键阶段（重置到临界状态开始，每方法 50 回合）和更真实的全任务（从 home 位置开始）。

最有意思的一格：它自己发明了新动作Q4 · 涌现策略

基线 VLA 的样子

靠近插孔 → 稍微退回 → 重新调整 → 再试。有时要循环好几轮才插进去。嗯…再来…

RLT 的样子

一气呵成地怼进去。第一次没成也不撤退，而是保持压力 + 轻微扭动，利用接触的柔顺性把插头带进孔里。

嗯——咔！

为什么这段重要 这个"压住再扭"的动作示教数据里根本没有，纯粹从在线探索里长出来。它证明了 RL 不只是把模仿学得更熟，而是真能翻过示教数据的天花板。

诚实的局限（论文自己写的）

整套流程目前还离不开人：发奖励信号要人判断成功失败，纠正要人接管，切换时机也需要人示范。论文说这些原则上都能自动化——用奖励模型、用进度预测——但那是未来工作。

作者最后抛出的观点值得记一下：当"上岗后改进"足够快且可靠时，预训练的角色就退化成"提供一个好的起点"，最终最强的策略是靠强化学习自己探索出来的。

一张便签总结

RLT = 冻住的 π0.6（眼睛 + 草稿）＋ 一颗 2048 维 RL Token（用"复述考试"压出来的状态表征）＋ 按 10 步动作块决策的小 actor-critic（缩短信用分配）＋ 抄着改 + λ 正则 + 50% 参考 dropout（局部精修而非乱撞）＋ 人类给稀疏奖励和接管。

换来的是：四个亚毫米精度任务上，关键阶段最高 3× 提速、螺丝成功率 20%→65%，训练只要几十分钟到几小时真机数据，某些动作比专家遥操作还快。
