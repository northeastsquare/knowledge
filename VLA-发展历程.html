00 / 定义与边界

什么才算 VLA？

先划清边界。否则 SayCan、Diffusion Policy、π0 会被混在同一个筐里。

VLA（Vision-Language-Action，视觉—语言—动作模型）：以预训练的视觉语言模型（VLM）为骨干，输入图像和语言指令（通常还有本体状态），端到端地直接输出机器人动作的策略模型。这个说法由 RT-2（2023）正式提出。

πθ( at:t+H | It1..n, ℓ, qt )，其中 θ 从 VLM 初始化

两个缺一不可的条件：① 语义来自大规模预训练，从而继承互联网的视觉与语言常识；② 动作由同一个网络直接生成，不经过手工定义的技能接口。动作头可以是离散 token、扩散、流匹配，也可以是它们的混合。

它的最小闭环是：看见观测 → 对齐目标 → 生成动作 → 适配身体 → 执行并得到反馈（见 06）。

动作：经过手工接口 / 技能库
动作：网络端到端直接输出
语义：大模型预训练
LLM / VLM 规划器SayCan、Inner Monologue、Code as Policies、VoxPoser。大模型只负责“想”，执行交给技能库或优化器。
VLART-2、OpenVLA、π0、GR00T、Gemini Robotics。双系统 VLA 内部虽然分快慢两部分，但联合训练、端到端输出动作，仍属于这一格。
语义：任务专用 / 无
符号与模块化机器人Shakey、经典 TAMP。感知、规划、控制逐个手工搭建。
视觉运动策略端到端 visuomotor、Diffusion Policy、ACT。动作能力很强，但没有互联网语义先验。

世界模型（视频预测、V-JEPA 2 等）不属于这四格中的任何一格，它回答的是“动作会带来什么后果”，可以给 VLA 提供想象、规划或奖励。RT-1 落在右下格向右上格过渡的位置：端到端输出动作，但语言只是一个编码向量，没有 VLM 骨干。

02 / 八个阶段

沿着“问题 → 突破 → 代价 → 被谁接手”读

不要背论文名。每个阶段先问：它想把什么做成通用能力，又留下了什么缺口给下一阶段？

P01960s
—2000s
阶段 0 · 符号与模块化

先把世界拆成可以计算的模块

感知、状态估计、规划、控制各司其职。系统可解释、可验证，但一碰到真实世界的长尾就失效。

问题
机器人怎样在不确定的环境里理解指令、规划步骤并执行？
突破
Shakey 用 STRIPS 做符号规划；SHRDLU 在积木世界里把自然语言变成操作，是 VLA 在语义一侧的远祖。此后又有视觉伺服、SLAM、PDDL 和任务与运动联合规划（TAMP）。
代价
误差在模块之间累积；换场景、换物体、换任务，规则就得重写。
被谁接手 →
ALVINN（1988）已经证明“像素直接到动作”可行，缺的只是数据和算力，这正是 P1 要补的。
为什么是这时候：符号 AI 是当时唯一可行的 AI 范式，算力只够支撑规则系统和小规模搜索。
P12013
—2018
阶段 1 · 深度学习进入控制

让像素直接长出策略

CNN 把感知和控制连成一条可以训练的通路，机器人第一次能够自己学会“看哪里、怎么动”。

问题
手工特征太脆弱，复杂的接触和视觉变化很难写成规则。
突破
端到端视觉运动策略（2015）；14 台机械臂的抓取农场（2016）；QT-Opt 在真机上做大规模 RL（2018）；Domain Randomization 开启了 sim-to-real。
代价
一个策略只对应一个任务、一台机器人；真机样本极贵，遇到分布外状态就会漂移（DAgger 早在 2011 年就指出了这种复合误差）。
被谁接手 →
P2 把数据从“一台机器、一个任务”扩展到“多台机器、多个任务”，并引入预训练表征。
为什么是这时候：AlexNet（2012）之后，视觉表征可以端到端学习；GPU 也让在线训练卷积策略变得可行。
P22019
—2021
阶段 2 · 规模化数据与预训练表征

从一个任务走向很多任务

多机器人数据集、离线 RL 和 CLIP 式的视觉语言表征，让“一个策略学很多事”第一次显得可行。

问题
每个新任务都要重新采数据、重新训练，能不能复用已有的数据和表征？
突破
RoboNet 汇集多机器人数据；CQL 等离线 RL 方法能从固定数据中学习；CLIPort 把 CLIP 的语义接到操作上；BC-Z 用语言或视频作为条件，实现了零样本任务泛化。
代价
语言只是一个条件向量，模型并没有真正理解语言；机器人数据量仍然比互联网数据小好几个数量级。
被谁接手 →
P3 换了个思路：既然语言模型已经懂了，就让大模型直接当“大脑”。
为什么是这时候：Transformer 和 CLIP（2021）让“预训练 + 迁移”在视觉与语言领域成为默认范式，机器人领域开始照搬这套做法。
P32022
阶段 3 · 语言成为接口

大模型当大脑，策略当小脑

LLM 负责分解任务，技能库负责执行；与此同时，RT-1、Gato、VIMA 证明了单个 Transformer 能处理很多任务。

问题
机器人策略高度专用；语言模型懂很多，却不会在真实的时间尺度上控制手臂。
突破
SayCan 用技能的可行性（affordance）给 LLM 的计划打分；Inner Monologue 把环境反馈写回提示；Code as Policies 让 LLM 写控制代码。RT-1 用 13 万条真机示范训练 Transformer，输出离散动作 token。
代价
分层接口靠手工定义，LLM 的常识进不到低层动作里；RT-1 的语言只经过句子编码器，还没有 VLM 骨干。
被谁接手 →
P4 的 RT-2 去掉了中间接口：直接让 VLM 输出动作。
为什么是这时候：PaLM、GPT-3 这一代 LLM 已经具备可用的常识推理能力；Google 机器人团队则积累了一年多、十几台机器人的真机数据。
P42023
阶段 4 · “VLA”诞生，动作表示同时革命

VLM 学会输出动作，动作头学会生成

这一年同时发生了两件互相独立的事：语义一侧，VLM 被直接改造成策略；动作一侧，扩散模型和动作分块让模仿学习精度大幅提升。

问题
单个平台的机器人数据太少，无法支撑开放世界泛化；逐步回归式的模仿学习无法表达多峰、精细的动作。
突破
RT-2 把动作写成文本 token，与网页数据共同微调，正式提出“VLA”；Open X-Embodiment 汇集了 22 种机器人、527 项技能、100 万+ 条轨迹。Diffusion Policy 用去噪生成动作；ACT/ALOHA 提出了动作分块，并配套了低成本双臂硬件。
代价
离散动作 token 精度低、控制频率低，几十亿参数的模型只能跑到几 Hz；RT-2 闭源，社区无法复现；生成式动作头还没有接上 VLM。
被谁接手 →
P5 把这两条线合在一起：开源的 VLM 骨干配上扩散或 flow 动作头。
为什么是这时候：PaLI、PaLM-E 这类强 VLM 已经可以微调；扩散模型在图像生成上已被验证；多家实验室开始把数据集合并到同一种格式里。
P52024
阶段 5 · 开源通用策略与生成式动作头

从“一个 token”走向“一段连续动作”

开源模型和开放数据汇合。VLM 骨干配上 flow 或扩散动作专家，能以高频率输出连续的动作块。

问题
离散动作难以表达灵巧、连续、长时程的操作；不同的机器人又有不同的“身体语言”。
突破
Octo（扩散头，从头训练）和 OpenVLA（7B，离散 token）提供了开源基线；RDT-1B 把扩散策略扩大到 1.2B 参数；HPT 用“异构茎干 + 共享主干”的结构处理跨本体问题。π0 在 PaliGemma 上接了一个 flow matching 动作专家，以 50Hz 输出动作块。数据方面有 DROID、UMI、Mobile ALOHA。
代价
生成式动作头很难给出策略概率，给后来的 RL 埋下了难点；推理延迟高；在机器人数据上微调后，VLM 原有的知识会被侵蚀。
被谁接手 →
P6 处理“泛化与推理”，P7 处理“如何从经验中继续变好”。
为什么是这时候：OXE 和 DROID 提供了公共的预训练数据；Llama 2、PaliGemma 这样的开源 VLM 可以免费商用；低成本硬件（ALOHA、UMI）让更多实验室能够采集数据。
P62025
上半年
阶段 6 · 双系统、推理与开放世界泛化

慢思考配快执行，会推理也要来得及

工业界的模型集中出现，主流架构收敛到“VLM 慢系统 + 动作快系统”；训练配方开始关注怎样保住 VLM 原有的知识。

问题
VLM 推理慢，控制却要求高频；在陌生的家里执行长时程任务，需要拆解子任务和推理。
突破
Helix（S2 7–9Hz / S1 200Hz）、GR00T N1、Gemini Robotics、Hi Robot 都是分层或双系统结构；FAST 用频域压缩让动作 token 化重新变得可用；知识隔离（Knowledge Insulation）用离散 token 训练骨干、用 flow 推理，同时防止梯度破坏 VLM；π0.5 结合多源数据联合训练，在没见过的家庭环境里完成长时程任务。
代价
“会做一次”离“稳定地做很久”还很远；模型的表现仍受限于示范数据的质量，缺少自我改进的机制。
被谁接手 →
P7 把真实执行中的经验、奖励和人类纠正接回模型。
为什么是这时候：2024 年开源基线把门槛降了下来，资本随之大量进入人形机器人和通用机器人公司，工业界开始用上万小时的数据训练自家模型。
P72025H2
—2026
阶段 7 · 闭环：从经验中变好（进行中）

把经验、奖励与身体差异接回模型

VLA 不再只是一个推理一次就结束的模型，而是能被真机经验、仿真、奖励和人类反馈持续修正的行动系统。本库的大部分论文都在这一站。

问题
模仿学习的天花板就是示范者的水平；精细接触、动态目标、长时程任务的成功率难以继续提高。
突破
RECAP（π*0.6）用价值函数给优势打分，再以优势作为条件做策略提取；πRL 用 PPO 微调 flow VLA；RL Token 和残差 RL 只更新轻量的部件；FLASH、DynamicVLA、PUMA 处理时延和动态目标；世界模型和具身推理（V-JEPA 2、Gemini Robotics 1.5）提供想象与规划能力；π0.7 让模型可以按提示调整行为。
代价
奖励稀疏，真机探索既昂贵又难保证安全；评测缺乏统一、可复现的标准；“做一小时不出错”仍然是开放问题。
下一站 ？
可能的方向：用世界模型做规划和评测；持续学习；用人类视频做规模化预训练。见 05 争论。
为什么是这时候：基础 VLA 已经足够强，可以作为 RL 的起点；部署规模扩大后积累了大量自主执行的数据和人类介入记录。
03 / 五条技术主线

把散点连成线

阶段回答“那时发生了什么”，主线回答“某个问题是怎样一步步被推进的”。新论文通常只推进其中一两条线。

① 动作表示：动作长什么样？

连续值、离散 token 还是生成式分布？一次输出一步还是一段？

连续回归端到端 visuomotor，MSE 回归，难以表达多峰分布
离散分箱RT-1 / RT-2 / OpenVLA，每个维度 256 个 bin
动作分块ACT：一次预测 H 步，减少复合误差
扩散Diffusion Policy、Octo、RDT-1B
流匹配π0：更少的积分步数，更适合高频控制
压缩 tokenFAST：DCT + BPE，让自回归也能处理高频动作
混合知识隔离：用离散 token 训练骨干，用 flow 推理

前沿与本库：生成式动作头怎样做 RL（πRL、为什么取 log），怎样加速推理（FLASH）。

② 骨干与架构：谁来“想”，谁来“动”？

单一网络还是分层？语义知识放在哪里？

CNN 策略2015 年的端到端 visuomotor
LLM + 技能库SayCan、Code as Policies
机器人 TransformerRT-1、Gato、Octo，从头训练
VLM 骨干RT-2（PaLI-X）、OpenVLA（Llama 2）
VLM + 动作专家π0：共享注意力，独立权重
双系统Helix、GR00T N1、Gemini Robotics、Hi Robot

前沿与本库：统一多种任务、环境和构型（Qwen-VLA）；可按提示调节的通才模型（π0.7）；把两条主干拆开来看（拆机手册）。

③ 数据：从哪里来、有多少、多杂？

泛化的边界往往由数据决定，而不是由模型决定。

单机自采一个实验室、一台机器
抓取农场14 台机械臂、80 万次抓取
真机遥操作RT-1：13 台机器人、13 万条示范
跨本体汇总RoboNet → Open X-Embodiment
野外采集DROID、UMI 手持夹爪
人类视频GR-1、LAPA 潜在动作
合成数据InternData-A1、仿真中的残差 RL

前沿与本库：合成数据能否替代真机数据（InternData-A1）；用 3D/4D 感知增强输入（D4RT）；用 跨本体 数据统一动作空间。

④ 训练范式：模型从什么信号里学？

只靠模仿，还是还要靠奖励和纠正？

行为克隆BC，外加 DAgger 式的纠正
真机 RL / 离线 RLQT-Opt、CQL
与网页数据共训RT-2：保住 VLM 的知识
预训练 + 后训练π0：先学广，再学精
知识隔离阻断动作头梯度回传到骨干
RL 微调RECAP、πRL、RL Token、残差 RL

前沿与本库：该更新整个模型、噪声空间、残差头还是 RL token？（VLA-RL 全景、RLinf 原理对比、π0.6 RECAP）

⑤ 执行与实时性：来得及做吗？

模型推理需要时间，世界却在推理期间继续变化。

开环执行先规划，再执行
闭环重规划Inner Monologue：把反馈写回提示
动作块 + 时间集成ACT：平滑地衔接相邻动作块
快慢双频Helix：S1 以 200Hz 执行
投机推理 / 动态目标FLASH、DynamicVLA、PUMA

前沿与本库：感知—执行时延导致的观测与动作错位（DynamicVLA、PUMA）。

05 / 争论与未解问题

没有定论的地方，才是值得读论文的地方

“观点”标签之后的内容是本文的判断，不是共识。

离散 token 还是连续生成？

A
离散 token 能直接复用 LLM 的训练设施，语言跟随能力强，训练稳定（RT-2、OpenVLA、FAST）。
B
连续生成精度高、推理快，适合高频控制（Diffusion Policy、π0）。
现状
观点正在走向混合：π0.5 和知识隔离用离散 token 训练骨干、用 flow 推理。问题已经从“二选一”变成“哪一阶段用哪种”。

本库：π0.5 测验

端到端还是分层 / 双系统？

A
端到端没有手工接口，信息损失最少（RT-2、π0）。
B
分层能把慢推理和快控制解耦，可解释，长时程任务也更好做（Hi Robot、Helix、GR00T）。
现状
观点“双系统 + 联合训练”是目前工业界的主流折中。高层输出语言子任务还是隐变量，仍未定论。

机器人领域存在 scaling law 吗？

A
数据量和多样性增加时，泛化稳定提升（OXE / RT-X 的正迁移、π 系列的数据配比实验）。
B
机器人数据比互联网数据少好几个数量级，又存在构型差异，目前看到的是“数据多样性的规律”，未必是参数量的规律。
现状
观点多样性（场景、物体、本体）的作用比数据总量更明确；参数量的 scaling 还缺少严格的对照实验。

真机、合成还是人类视频？

A
真机遥操作数据质量最高，但最贵（DROID、π 系列）。
B
合成数据和仿真成本低、规模大（InternData-A1）；人类视频的数量几乎无限（GR-1、LAPA）。
现状
观点多源联合训练是共识，分歧在配比和对齐方式上：sim-to-real 的差距要靠残差 RL 或少量真机数据来弥补。

本库：InternData-A1、残差 RL

需要显式的世界模型吗？

A
能预测后果才能规划、才能安全地探索；世界模型还可以用来评测和产生奖励（V-JEPA 2）。
B
隐式的策略已经足够好用，像素级的预测代价高，而且未必有用。
现状
观点世界模型最先落地的用途很可能是评测和数据生成，而不是在线规划。

RL 应该更新模型的哪一部分？

A
更新整个模型，上限最高（πRL 用 PPO 微调 flow VLA）。
B
只更新轻量部件，样本效率高、更安全（RL Token、残差 RL、噪声空间 RL）；或者不直接做 RL，用优势作为条件做策略提取（RECAP）。
现状
观点真机场景偏向轻量部件或离线策略提取，仿真场景偏向更新整个模型。Actor–Critic 框架是这些方法的共同骨架。

本库：VLA-RL 全景、RL Token

怎样评测才可信？

A
仿真基准（LIBERO、SimplerEnv、CALVIN）可以复现、成本低。
B
这些基准已经接近饱和，仿真分数和真机表现的相关性也有限；而真机评测各家场景不同，结果无法横向比较。
现状
观点评测是当前最被低估的瓶颈。读论文时，优先看真机实验的设置、试验次数和失败案例。

“会做一次”到“可靠地做一小时”

A
靠更多数据和更大模型就能逐步提高可靠性。
B
需要新的机制：失败检测、恢复、持续学习、记忆。
现状
观点从 P7 的趋势看，从部署经验中学习（RECAP）是目前最有说服力的路径，但安全约束和奖励来源仍然没有解决。

07 / 学习路径与自测

按问题走，不按年份背

三条路径分别对应三类问题。每条路径读完后做一下自测，答案折叠在下面。

A · 动作怎么生成

从“回归一个值”到“生成一段分布”

  1. Diffusion Policy
  2. ACT / ALOHA
  3. π0 精读
  4. FAST → π0.5 测验
  5. Realtime-VLA FLASH
为什么 MSE 回归在示范数据有多种做法时会失败？

当示范存在多峰（比如从左边绕或从右边绕）时，MSE 的最优解是各个峰的平均，得到的动作可能哪一种都不是，甚至直接撞上障碍物。扩散和 flow 学的是整个分布，可以采样到其中一个峰。

动作分块为什么能减少复合误差？

一次预测 H 步，相当于把需要做决策的次数减少到原来的 1/H，误差累积的机会随之减少；动作在块内也更连贯。代价是对突发变化的响应变慢，所以需要时间集成或实时分块来弥补。

FAST 解决了离散 token 的什么问题？

按时间步逐维分箱，在高频控制下会产生大量高度相关的 token，自回归模型很难学好。FAST 先用 DCT 把动作块变换到频域，再用 BPE 压缩，token 更少、信息更集中。

B · 语言与泛化

大模型的常识是怎样一步步进入手臂的

  1. SayCan
  2. RT-2
  3. OpenVLA
  4. π0.5 测验
  5. Qwen-VLA → π0.7
SayCan 和 RT-2 的根本区别是什么？

SayCan 中的 LLM 只在预先定义好的技能里做选择，并用可行性函数给每个技能打分，动作由技能策略执行；RT-2 让 VLM 直接输出动作 token，没有中间的技能接口。前者属于 00 节中的“LLM 规划器”，后者属于 VLA。

RT-2 为什么要和网页数据一起共训？

如果只用机器人数据微调，VLM 会逐渐遗忘视觉语言知识，泛化能力随之下降。把网页 VQA 数据混进训练集，可以保住语义能力，让模型能理解训练中没出现过的物体和指令。

OpenVLA 用的是哪种动作头？

离散 token：每个动作维度分成 256 个 bin，由 Llama 2 骨干自回归地输出，与 RT-2 的思路相同。它不是扩散头，也不是 flow 头。

C · 闭环与 RL

模型怎样超过示范者的水平

  1. 为什么取 log
  2. πRL
  3. π0.6 RECAP
  4. RL Token → 残差 RL
  5. VLA-RL 方法全景
为什么 flow VLA 做策略梯度比离散 token 难？

策略梯度 需要计算 log π(a|s)。离散 token 可以直接从 softmax 读出这个值；flow 和扩散通过多步去噪生成动作，边缘似然无法直接计算，必须把去噪过程建模成 MDP（πRL），或者绕开似然（RECAP、残差 RL）。

RECAP 为什么不直接做 PPO？

RECAP 先训练价值函数来估计优势，再把“优势是否为正”作为条件输入去训练策略，属于离线、监督式的策略提取。这样可以复用示范数据、自主执行数据和人类纠正数据，避免在真机上做高方差的在线策略梯度。

只更新 RL token 或残差头有什么好处和代价？

好处：参数少、样本效率高，冻结的骨干保留了预训练能力，探索也更安全。代价：改进的上限受冻结骨干的表征限制，很难学到骨干从未见过的新技能。
