① 整模型 RL

3 个

直接更新整个 VLA。上限最高、能真正改变行为模式，但计算和样本成本最贵，on-policy 方法尤其难上真机。RECAP 用离线 RL绕开在线探索，是这一类的实用代表。

RECAP（π0.6）
优势条件策略抽取：价值函数估每步优势，把「演示 + 自主 rollout + 人类干预」全喂给模型，吞吐 >2×。
SimpleVLA-RL
PPO 类整模型 RL，面向规模化 VLA 训练。
DPPO
Diffusion Policy 上的 PPO，把策略梯度用到扩散策略。

② 噪声 / 潜空间 RL

3 个

冻结 VLA，但在生成过程内部做 RL——要么微调动作专家（πRL），要么学一个「选噪声 / steer 去噪」的小策略（DSRL、GR-RL）。好处是保留 VLA 的生成能力，探索天然被约束在 VLA 能产出的动作内。

πRL（Flow-Noise / Flow-SDE）
把流去噪 MDP 化让 log π 可解；冻结 VLM 只微调 300M 动作专家；LIBERO 57.6→97.6。
DSRL
在 flow VLA 的潜噪声空间学策略，选噪声喂给冻结生成器。
GR-RL
多阶段长程任务（系鞋带）：先过滤 BC，再在线学噪声预测器 steer 潜空间。

③ 残差策略（冻结 VLA）

4 个

冻结 VLA，学一个对 VLA 动作做修正的残差。最简单、最省算力，但大多局限在单步动作（PLD、ConRFT、Policy Decorator），信用分配链更长；Object-Centric 用物体位姿缩小观测空间做到零样本 sim-to-real。

Object-Centric Residual RL
物体位姿观测 + 仿真噪声注入，纯仿真训练零样本上真机，42%→76%。
PLD（Probe-Learn-Distill）
Cal-QL 预训 critic，再学单步残差，可选蒸馏回 VLA。
ConRFT
冻结 encoder 微调 action head，一致性目标 + 二值奖励分类器。
Policy Decorator
残差 × 手工超参加到 VLA 预测；仅仿真、需百万级步。

④ RL token（本文路线）

1 个

在「残差 / 轻量头」之上更进一步：不直接拿 VLA 高维特征，而是先抽一个紧凑表示（RL token），再训轻量 actor-critic，并且用参考动作 + KL 正则锚定、用动作块缩短信用分配。是「冻结 VLA + 轻量 RL」里数据效率最极致的做法。

RLT（RL Token）
RL token（信息瓶颈表示）+ actor 以参考动作 ã 为条件 + KL 正则 + reference dropout；真机几分钟~几小时，关键阶段提速最高 3×。

⑤ 从零小模型（对照基线）

1 个

完全不用 VLA，从零训小 actor-critic + ResNet 编码器。样本效率尚可，但丢了 VLA 的泛化与行为先验，精度上限被小模型限制。作为对照，反衬出「用 VLA 先验」的价值。

SERL / HIL-SERL / RL100
off-policy actor-critic + ResNet，真机小时级；无 VLA 先验。

怎么选

  • 有仿真器 + 要大改：走 ①整模型 或 ②噪声空间（πRL），上限高、靠密集奖励批量练。
  • 只能上真机 + 要快 + 保泛化：走 ④RL token，几分钟到几小时精调高精度阶段。
  • 有物体位姿可观测 + 想零样本 sim-to-real：③里的 Object-Centric 残差 RL。
  • 只想最小改动、短程任务：③里的 PLD / ConRFT（但注意单步动作的信用分配短板）。
  • 连 VLA 都没有 / 只想做个对照：⑤ SERL 类。
