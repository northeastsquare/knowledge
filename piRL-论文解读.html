πRL：流匹配 VLA 的在线强化学习微调

把流匹配 VLA 的去噪过程建模成马尔可夫决策过程（MDP），让动作似然变得可解，从而用 PPO 在线微调 π0 / π0.5——与「冻结 VLA + 轻量头」的 RL Token 正好是两条相反路线。

论文π-RL: Online RL Fine-tuning for Flow-based Vision-Language-Action Models
机构清华大学 · 华为
arXiv2510.25889
主题VLA · 强化学习 · Flow Matching

它解决的问题

流匹配（Flow Matching）VLA 通过迭代去噪 ODE生成动作，这把标准策略梯度 RL 卡住了：

  • 动作似然不可解——执行动作的对数似然 log π(a|o) 没有闭式表达，PPO / GRPO 需要的概率比算不出来；
  • 去噪过程是确定性的——没有天然的随机性可供探索。

于是 π0 / π0.5 这类流模型无法像普通高斯策略那样直接做在线 RL 微调。πRL 的目标就是给流模型补上「可计算似然 + 可探索」这两个缺口，让它们在仿真里用 PPO 大幅提分。

方法主线

  1. 把去噪过程重写成 MDP：每步去噪当作一个状态转移，配一个高斯转移分布，整条去噪链的对数似然就变成可计算的乘积。
  2. Flow-Noise：注入可学习的噪声网络，去噪每步服从 N(μ_τ, σ_τ²)——均值来自原 ODE 的欧拉步，方差由噪声网络给出；训练后丢弃噪声网络，推理退回确定性。
  3. Flow-SDE：把确定性「概率流 ODE」换成保边际分布的等价 SDE，在两层 MDP 里同时建模去噪步骤与环境交互，探索来自 SDE 的随机项。
  4. PPO + GAE 优化：动作块当作一个宏步、块内奖励求和；RL 阶段冻结 3.3B VLM，只微调 300M 动作专家（省显存）。

输入、输出与数据流

环节说明
输入观测 o图像 + 语言指令 + 本体感受
VLM 骨干（3.3B）冻结，只输出条件表征
动作专家（300M）被 RL 微调；去噪 ODE 被改写成 MDP / SDE
Flow-Noise / Flow-SDE给去噪每步引入高斯随机，让 log π 可算
输出动作块（多步动作，视作一个宏步）
奖励仿真任务奖励（块内求和）

训练或运行方式

  • 先在目标任务上做 SFT（少样本，如 ManiSkill 用 16,384 合成 episode）；
  • 再用 PPO + GAE 在线 RL 微调动作专家，训练于 8× NVIDIA H100；
  • critic 位置：π0.5 的 critic 接 VLM 输出，π0 的 critic 接动作专家（对去噪轨迹上的专家价值取平均近似观测价值）；
  • 并行仿真环境加速（ManiSkill 320 envs）。

与 RL Token 的对比 VS

两篇都承认「整模型 RL 太贵」，却走了相反方向：πRL 保留并改造 VLA 的生成过程，在噪声/潜空间里做 RL；RL Token 彻底冻结生成过程，另起一个轻量头在动作块空间做局部精修。对比读能看清「VLA 在线 RL」这条谱系的两个端点。

维度πRLRL Token
改什么微调 300M 动作专家（冻结 VLM）冻结整个 VLA，只训轻量 actor-critic
动作空间流匹配的噪声 / 潜空间动作块空间（以参考动作 ã 为条件）
似然处理Flow-Noise / Flow-SDE 让 log π 可解高斯 actor，无需原模型似然
训练环境在线 RL，并行仿真（ManiSkill 320 envs）真实机器人在线 RL（15min ~ 5h）
奖励仿真密集 / 任务奖励人类稀疏 0/1 标签
正则 / 锚定从 SFT 初始化继续 RL，无显式 KLKL 正则锚定到 VLA 参考动作 + reference dropout
成本重算力（8×H100）轻量、低数据
适用有仿真器、求大幅提升、可离线批量真机、无仿真、需快速、保 VLA 泛化

一句话概括：πRL 的上限可能更高——它能在生成过程内部改变行为模式（LIBERO 单点 +40 个百分点），但依赖仿真器与算力；RL Token 更便宜、更快、能直接上真机，但只在 VLA 参考动作附近做局部精修，收益被限制在「已有好行为」的邻域内。

我真正学到的内容

  • 流模型也能做 RL：把去噪 ODE / SDE 写成 MDP、让似然可解，是打通 PPO 的关键一步，也是和「绕开生成过程」路线（RL Token / DSRL）最本质的分野。
  • 「冻结主干、只微调动作专家」是 VLA + RL 里性价比很高的折中——既控制显存，又保留 VLM 的视觉语言理解。

可复用设计

  • Flow-Noise / Flow-SDE 的 MDP 化技巧：可套到任何 flow / diffusion 策略上，作为「让扩散策略可强化学习」的通用件。
  • 冻结 VLM 只训动作专家：显存友好，适合个人或中小团队复现。

疑问与风险

  • 高度依赖高质量仿真器；MetaWorld OOD 无增益，说明跨任务泛化有限。
  • 只微调动作专家，语言 / 视觉理解不更新，上限受冻结骨干制约。
  • 重算力（8×H100）个人难以复现，与 RL Token 的「轻量真机」形成鲜明对比。

后续动作

  • 把 RL Token、Object-Centric Residual RL、DSRL 放到一起，理清「VLA 在线 RL」从整模型 → 噪声空间 → 冻结 + 残差 → 冻结 + 轻量头 的完整谱系。
  • 读 π0.6 / RECAP，看 PI 自己的整模型离线 RL 路线与 πRL 的差异。
  • 评估在自己机器人上的落点：有仿真器就走 πRL / DSRL 路线，只能上真机就走 RL Token 路线。
