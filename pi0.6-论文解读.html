π0.6：会从经验中学习的 VLA

通过自主交互经验与强化学习（RECAP）持续提升的 VLA，突破示范数据的性能上限

论文π0.6: a VLA That Learns From Experience
机构Physical Intelligence
arXiv2511.14759v2
主题VLA · 强化学习 · 经验学习

它解决的问题

纯模仿学习训练的 VLA 存在两个天花板：一是复合误差（compounding errors），策略一跑偏就越滚越远；二是性能上限被示范数据锁死——最多只能做到和人类遥操作示范一样好，没法更快、更稳、更适应新环境。

自然的答案是"让机器人像人一样练出来"——用强化学习（RL）在真实部署中自己收集经验、纠正自己的错误。但把 RL 套到大型 VLA 上，难点集中成三件事：

  • 大规模模型上做 RL 要稳定可扩展：传统策略梯度（PPO/REINFORCE）对 flow-matching / diffusion 这类没有可计算对数似然的动作模型很难直接套；
  • 数据是异质的：既要示范数据，又要自主 rollout，还要专家遥操作纠错，几路数据得融进同一次学习；
  • 真实世界的奖励信号暧昧又随机：只有"成功/失败"这类稀疏结果反馈，噪声大、延迟高。

本文的贡献是把这三件事打包成一个通用配方 RECAP，并证明它能把通用 VLA（π0.6）在叠衣服、做咖啡、装纸盒这些长时程精细任务上练到"实用级"水平。

方法主线

RECAP = RL with Experience and Corrections via Advantage-conditioned Policies（通过优势条件化策略，用经验与纠错做 RL）。这里的优势衡量动作相对参考行为好多少；RECAP 将它作为策略的输入条件，不等同于 PPO 的策略梯度更新。整条流水线只有三个子程序，反复循环即可： ⟨/⟩ 代码

  1. 预训练一个"带优势条件化"的通用 VLA（π0.6）：在数万小时、多任务多机器人的离线数据集上，先训一个分布式价值函数，再训一个以"二值优势指示 I_t"为输入的策略，用离线 RL 的方式把 RL 能力烙进底座模型；
  2. 任务级监督微调（SFT）：用目标任务的示范数据微调 π0.6，此阶段把优势指示固定为 True，等价于普通行为克隆，得到初始策略 π0；
  3. 数据收集：部署策略在真实机器人上跑 episode，给每集打"成功/失败"标签（即奖励），并可选地让专家遥操作介入纠错（human-gated DAgger 风格）；
  4. 价值函数更新：用至今收集到的全部数据（示范 + 自主 + 纠错）训练价值函数，让它估计"离成功完成还差多少步"；
  5. 优势条件化策略提取：用价值函数算出每个动作的优势 A，按阈值二值化成 I_t 塞进模型前缀重新微调策略——得到一个在参考策略基础上单调改进的新策略。回到第 3 步再循环，可做多轮。

核心洞察一句话：不跟策略梯度死磕，而是把"这个动作比当前策略好还是差"作为一个二元条件喂回模型，用监督学习的方式完成策略改进。

数据流（一轮迭代）
  1. 部署：当前策略 πk-1 在机器人上自主执行，收集 episode；
  2. 打标签 / 纠错：每集标注成功（奖励 0）或失败（奖励 -Cfail，其余步 -1）；专家可中途遥操作介入，介入动作被强制标为 I_t = True；
  3. 训价值函数：从预训练 checkpoint 出发，用所有数据微调 Vk（预测"负的剩余步数"）；
  4. 估计优势：A(o_t,a_t) = Σ_{t}^{t+N-1} r + V(o_{t+N}) − V(o_t)（部署后取 N=50 步前瞻）；
  5. 二值化：按任务阈值 τ 把优势映射成 I_t ∈ {True, False}；
  6. 微调策略：把 I_t 作为文本前缀输入，重新训练 πk，回到第 1 步。

训练或运行方式

模型与奖励设计

  • π0.6 架构：由 π0.5 进化而来——基础 VLM 换成 Gemma 3 4B，动作专家增大到 860M 参数，预训练数据加入多个机器人平台；沿用 KI（Knowledge Insulation）训练法：flow matching 动作专家用 stop-gradient 隔离，离散动作走 FAST 分词，语言子任务 ŷ 先预测、再条件化动作生成。
  • 价值函数：与策略同架构、但用更小的 670M VLM 骨干（也初始化自 Gemma 3），分布式输出 201 个 bin；为防过拟合还混入少量多模态网页数据联合训练。
  • 稀疏奖励：r_t = 0（成功那步）、-C_fail（失败那步）、否则 -1——等价于让价值函数预测"离完成还差多少步"的负值。

关键训练细节（决定成败的超参）

  • 优势阈值 τ：预训练时取每个任务价值 30% 分位；微调时取每轮 40% rollout 优势为正；对"示范太好导致慢"的叠 T 恤任务，收紧到只留 10% 正优势——用 τ 调节"正则化 vs 最优性"的权衡，替代 classifier-free guidance 的权重 γ；
  • 优势条件化 dropout：训练时随机 30% 概率丢弃 I_t，让模型同时学会条件/无条件策略，推理时才能做 CFG（γ ∈ [1.5, 2.5] 适度锐化）；
  • 每次迭代从预训练 checkpoint 微调，而非从上一轮模型续训，避免多轮漂移；
  • 迭代式离线更新：批量收集数据 → 重训 → 再收集，而非完全在线的 RL 循环。

关键结果

三大真实任务：叠衣物（含 11 类衣物的多样化版本）、做咖啡（双份浓缩，200 秒内完成）、组装纸盒（600 秒内，工厂部署场景）。每集耗时 5–15 分钟。

与基线 / 消融对比

  • 对比基线：预训练 π0.5、监督预训练 π0.6、RL 预训练 π0.6、π0.6 离线RL+SFT——最终 π0.6（RECAP）在所有任务上显著胜出；
  • 策略提取方法对比：同数据下，AWR 成功率尚可但策略更慢、吞吐低；PPO 需极小的信任域（ε=0.01）才能稳定，且性能不佳——两者都远逊于优势条件化；
  • 离线 RL + 高质量 SFT 本身已优于普通 SFT，是后续在机 RL 的好起点。

我真正学到的内容

  • 优势条件化是把 RL 塞进生成式 VLA 的最省力姿势：不碰策略梯度的对数似然难题，把优势二值化成一句"Advantage: positive/negative"当文本前缀，策略改进就退化成普通的监督学习。
  • 稀疏奖励可以很便宜地定义：把价值函数设成"负的剩余步数"，成功=0、失败=大负值、其余=-1，几乎任何任务都能套，还顺带把"速度"纳入优化目标（步数越少价值越高）。
  • 示范数据只是起点，自主经验 + 纠错才是超额收益来源：离线 RL+SFT 已强于纯 SFT，但真正的翻倍来自机载自主 rollout 与人类纠错的迭代循环。
  • 用一个更小的 VLM 当价值函数是可行且便宜的：670M 骨干在训练时即时推理，开销可忽略。
  • 阈值 τ 比 CFG 权重 γ 更好调：高 CFG 权重会把动作分布推向支撑集边界（动作变激进），而用 τ 在训练阶段直接控制"最优性 vs 正则化"更稳。

可复用设计

  • 二值优势指示作为文本前缀："Advantage: positive/negative" 直接接入 VLA 输入，只影响动作对数似然，不动语言与子任务部分；
  • 优势条件化的闭式改进：π̂(a|o) ∝ π_ref(a|o) · π_ref(a|I,o)/π_ref(a|o)，配合 30% dropout 即可在推理时用 CFG（γ>1）进一步锐化，无需额外训练；
  • 分布式价值函数 + 归一化：201 bin 分布预测、每任务按最大 episode 长度归一化到 (-1,0)，跨任务可比；
  • 人类纠错强制 I_t=True：把专家介入动作一律标成正优势，融进同一数据集，不必单独处理；
  • 每次迭代从预训练 checkpoint 重启微调：防止多轮漂移的实用技巧。

疑问与风险

  • 还不是全自主：奖励标注、专家纠错、环境 reset 都依赖人；作者自己也把"自动化这些环节"列为未来方向；
  • 探索基本是贪心的：靠策略随机性和人类介入探索新解，缺乏更精妙的探索机制；
  • 是"迭代式离线"而非"全在线"RL：批量收数据再重训，实时性弱；
  • 价值函数用的是 on-policy 蒙特卡洛估计：论文承认比经典 off-policy Q 估计更弱，只是胜在简单可靠；
  • 阈值 τ 是逐任务的启发式（30% / 40% / 10%），迁移到新任务可能要重新调。
