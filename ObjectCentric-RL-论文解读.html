物体中心残差 RL：零样本 Sim-to-Real 增强 VLA

用物体位姿做观测的残差 RL，纯仿真训练、零样本迁移到真机，成功率 42%→76%

论文Object-Centric Residual RL for Zero-Shot Sim-to-Real VLA Enhancement
机构KAIST · 微软亚洲研究院
arXiv2606.18953v1
主题强化学习 · Sim-to-Real

它解决的问题

VLA（视觉-语言-动作）模型靠海量遥操作演示做模仿学习，泛化能力强，但在需要精确物理交互的任务上很脆弱：模仿学习的小误差会随时间累积，一碰到没见过的状态就失败。强化学习（RL）本可以通过在线交互来恢复，但直接给现代 VLA 上 RL 很难——很多 VLA 用扩散（diffusion）或流匹配（flow matching）生成动作，其迭代去噪过程无法直接用标准策略梯度求导。

残差 RL（在冻结的 VLA 之上学一个轻量修正策略）是一条自然的路，但现有做法都卡在同一个 Sim-to-Real（把仿真中训练的策略迁移到真实机器人）困境上：

路线代表失败原因
特权状态蒸馏ResiP仿真里用接触力等特权状态，部署时必须蒸馏成图像策略，蒸馏过程损失性能
图像残差 RLRialTo / ResFiT / PLD直接吃图像，但视觉域差距（光照、纹理、背景）太大，仿真训练的策略无法零样本迁移
真机 RLResFiT / PLD直接在真机上训练，昂贵且不安全（需要安全探索、重置、奖励检测）

核心洞见：之前仿真残差策略迁移失败，是因为它的观测空间本身就是域相关的。与其费力去弥合两个域，不如把观测换成「在仿真和真机上都能一致获得」的量——6-DoF 物体位姿 + 本体感受 + 基础 VLA 动作。

本文要回答的问题：一个只在仿真里训练的 RL 策略，能不能零样本提升真机 VLA 的鲁棒性？答案是能——在真机 Franka Research 3 上五个任务平均成功率从 42% 提到 76%，全程没有任何真机 RL 或微调。

方法主线

整体是一条「真机演示 → 仿真孪生 → 仿真残差 RL → 零样本部署 → 反哺 VLA」的三阶段流水线，核心是让残差策略只观测跨域一致的物体位姿。

  1. Stage 1 · 遥操作回放，构建成对的仿真/真机 VLA：常规流程是在真机上采集遥操作演示、用 (RGB, 动作) 微调真机 VLA V_real；作者额外把同一批遥操作动作在 MuJoCo 里回放，渲染出平行仿真数据集，训练一个仿真 VLA V_sim。两个 VLA 被完全相同的动作监督，虽然视觉域不同，但动作分布是对齐的——这为「仿真里训练、真机上部署」埋下伏笔。
  2. Stage 2 · 物体中心残差 RL：残差策略 π_res 的观测定义为 s_t = [s_obj, s_prop, a_base]——任务相关物体的 6-DoF 位姿、本体感受（末端位姿 + 夹爪）、当前 VLA 基础动作。用 TD3 训练一个 2 层 MLP 残差网络，并用位姿噪声注入 + 位姿 dropout 增强鲁棒性。
  3. Stage 3 · 零样本真机部署：部署时 V_real 和 π_res 都冻结，无任何训练或适配。每个时间步用 FoundationPose + SAM2 估计物体位姿和跟踪置信度 c_t；当 c_t 低于阈值 0.5 时把位姿输入置零，触发训练时学到的 dropout 回退策略。
  4. （附加）VLA 自我改进：把残差修正后成功跑通的真机轨迹，与原始演示合并，用来对基础 VLA 做监督微调（SFT），不需要额外的遥操作就能让 VLA 自我提升。

组合动作的公式是整个方法的核心：a_t = a_base ⊕ π_res(s_t)，其中 ⊕ 表示逐分量组合——位置和夹爪做加法、旋转做四元数乘法。

输入、输出与数据流

整个系统里有两条并行的信息流：基础 VLA（看图、低频出动作块）和残差策略（看位姿、高频做修正），最后在动作层面合成。

部署时的数据流（按时间步）

  1. 相机抓一帧 RGB；t mod H == 0 时查询冻结 VLA，拿到新动作块 A。
  2. 读出当前基础动作 a_base = A[t mod H]。
  3. FoundationPose(SAM2(图像)) 输出位姿 x̃_obj 与置信度 c_t；若 c_t < 0.5 则 x̃_obj ← 0（置信度门控 dropout）。
  4. 拼观测 s_t = [x̃_obj, s_prop, a_base]，残差网络输出 δ_t。
  5. 合成 a_t = a_base ⊕ δ_t，发给机器人执行。

为什么敢零样本迁移：三个观测分量里，本体感受是域不变的（误差 ≈ 0），基础动作因双 VLA 同数据训练而对齐（误差 ≈ 0），唯一有不可忽略噪声的是物体位姿——这正是训练时用噪声注入 + dropout 专门鲁棒化的部分。

消融实验

去掉的组件影响
位姿 dropout贡献最大去掉后对「检测失败」的韧性下降，各任务明显掉点
噪声注入帮助大对紧公差任务（tolerance 敏感）尤其重要
两者都去最差组合训练才能拿到最强的 sim-to-real 迁移

分析与泛化

  • 选择性修正：当基础 VLA 动作与目标方向对齐时，残差几乎不干预；偏离时才大力修正（余弦相似度分析），任务完成时间缩短 9%–22%。
  • 跨架构泛化：把基础 VLA 换成 π0.5，残差 RL 仍一致提升真机表现，说明物体中心接口与 VLA 骨架无关。
  • 强基础也不退化：对已经很强的 π0.5 基础（真机 17/20），残差学到「保持接近零」，成功率不降反微升。
  • 自我改进：用残差修正后的轨迹做 SFT，比用原始基础轨迹 SFT 的成功率更高、episode 更短，且无需额外遥操作。

我真正学到的内容

  • Sim-to-Real 的本质是「观测空间设计」，不是渲染或动力学对齐。与其把图像逼真渲染、把动力学调准，不如选一个跨域一致的观测（位姿 + 本体 + 基础动作），域差距从源头被缩小。
  • 「回放遥操作」是一招便宜又好用的域对齐：同一批动作在仿真里再跑一遍，就能训出一个动作分布与真机 VLA 对齐的仿真 VLA，省掉整条 3D 重建 + 蒸馏流水线。
  • 训练时随机 dropout，部署时置信度门控 dropout：把「随机丢位姿」做成训练增强，部署时位姿丢失就用置信度触发同样的置零回退——训练和部署被同一套机制打通，非常优雅。
  • 残差策略要「按需出手」：强基础 VLA 面前，残差学会输出接近零，不添乱；弱基础面前才大幅修正。这是残差框架天然的「安全网」性质。
  • 残差 RL 的输出可以被回收再利用：修正后的好轨迹聚合起来重训 VLA，形成一个无需人工标注的自我改进闭环。

可复用设计

  • 观测三件套：[物体 6-DoF 位姿, 本体感受, 基础动作]——一个低维、可迁移、信息充分的残差观测模板，几乎不挑基础策略。
  • 成对 VLA 训练：遥操作回放（仿 MimicGen 思路）构建仿真孪生 VLA，让「仿真训练、真机部署」成立。
  • 两级鲁棒化位姿：层级均匀噪声（每步重采样幅值）+ 整段置零 dropout，覆盖真实估计器的误差分布与偶发失败。
  • 分域动作合成：位置/夹爪做加法、旋转做四元数乘法——残差组合的正确姿势，避免旋转的加性误差。
  • 置信度门控回退：用跟踪置信度阈值把「随机 dropout」切换成「确定性 dropout」，作为训练-部署桥。
  • 异步位姿估计：位姿跟踪（18ms/帧）与控制环解耦，不让感知成为瓶颈。

疑问与风险

  • 只弥合了视觉 gap，没弥合动力学 gap：接触摩擦、夹爪柔顺性等仿真/真机差异仍在，接触密集任务里可能给出次优修正。
  • 依赖实时 6-DoF 位姿跟踪：完全遮挡或严重杂乱下 FoundationPose 会失效；失败案例里还出现了误检（锁定到镜面反光）和位姿漂移——都是「过了置信度门」的感知错误。
  • 任务相关物体要人工指定：离「开放世界」还有距离，需要从 VLA 注意力图里自动识别物体。
  • 残差只能修「轻度偏离」：无法把远超基础 VLA 训练分布的状态拉回来，本质仍是围绕基础策略做局部修正。
  • 亚毫米精度或极小物体：超过当前位姿估计精度上限，需要更高分辨率传感或触觉反馈。

  • 读代码/复现：找到论文项目页，看 MuJoCo 里「遥操作回放」和「位姿噪声注入」的具体实现，跑通 Cube Lift 的最小闭环。
